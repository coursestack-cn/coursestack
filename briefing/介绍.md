# 项目介绍

CourseStack（课栈）是一个面向校内课程的资料共享与问答平台。师生围绕课程整理资料、提出问题、分享解答，让资料和讨论能够跨学期积累，供后续修读同一课程的学生继续使用。

项目目前处于需求与方案讨论阶段，尚无应用代码。本目录用于组内提案，具体流程、技术选型和成员安排将在讨论后继续细化。

## 项目定位

课程是资料和讨论的主要归属。一门课程可以由多名教师共同教授，课程本身长期存在；学生的修读关系随学期变化，资料和问答则可以持续保留。

学生可以从本学期课程、历年课程和关注的课程进入学习内容。正式修读与主动关注分别记录，方便区分教学管理和个人兴趣；关注课程不是访问站内共享内容的前提。

公开讨论使用的名称与真实学籍信息分开。学生可以使用公开名称参与讨论，教师在本学期的授课与修读关系范围内查看必要的学籍信息。

## 面向的用户

| 用户 | 主要活动 |
| --- | --- |
| 学生 | 查找和分享资料，提出问题、回答和评论，关注课程、收藏内容、查看通知 |
| 教师 | 组织课程、导入学生名单，分享资料、参与讨论，采纳答案、配置课程加分，维护课程内容 |
| 管理员 | 统一建立师生账号，维护身份和权限，进行全站管理 |

## 一条典型流程

管理员建立师生账号，教师组织课程并导入本学期学生名单。学生浏览课程资料，关联某个具体文件版本提问；其他学生和教师回答、评论和投票，课程教师采纳答案，并按课程配置记录加分。

资料发布新版本后，已有问题仍然关联原版本，收藏者可以收到更新通知。学期结束后，学生的本学期修读关系归入历年课程，课程内容继续保留。

## 首版范围

首版面向一所学校，优先完成账号与课程组织、资料版本、问答互动、个人学习空间、站内通知和内容管理的完整流程。

文件预览先覆盖 PDF 和常见图片，其他支持类型提供文件信息与下载。搜索先覆盖课程名称、资料信息、文件名和讨论文字。教务系统集成、文件正文全文检索和文件内部定位留作后续扩展。
