# 资料与文件

本文描述资料与文件版本的规则、接口和存储流程，前后端均已接入。接口结构见 [OpenAPI](../openapi/openapi.json)，数据定义见 [schema](../backend/src/db/schema.ts)；页面地址见[前端路由](./前端路由.md)，页面实现见[资料接入](../frontend/src/pages/README.md#资料接入)。

## 内容与版本

- `contents.kind=material` 表示一份资料，`title` 是唯一公开文件名，`body` 是 ProseMirror JSON 介绍，`tags` 与问题共用。没有分类，也不检测重复文件。
- 每次上传、每个版本只有一个文件。用户自行压缩后可以上传 ZIP，平台不负责打包。
- 文件名属于资料，重命名统一影响所有版本的下载名称。版本保存内部存储键、实际大小、MIME、上传者和时间；不保存另一份公开文件名，资料响应不暴露存储键。
- 新资料与上传 ID 使用无横杠 UUID。版本以 `(material_id, version)` 为主键，version 为正整数，对外标识写作 `materialId@version`（如积分流水的来源），不另存 UUID。版本号由数据库事务递增分配，移除版本也不复用序号。已发布版本的文件、存储键、大小、MIME 不可覆盖。
- 资料详情直接返回最新现存版本，介绍、版本选择、预览和评论属于同一页面。明确指定不可用版本时返回404，不自动替换版本。全部版本删除时介绍和评论仍保留，默认版本为 null。
- 评论属于整份资料，切换版本不切换评论。暂不提供版本更新说明，用户可在评论中说明变化。其他内容通过正文链接引用资料或版本，href 使用页面地址（如 `/materials/<id>/versions/2`），发布新版本不改写已有链接；资料下架或版本删除不会隐藏引用它的内容。
- 游客可查看介绍及现存版本元数据，预览、下载均需登录，不要求关注或修读课程。PDF、PNG、JPEG、GIF、WebP 可预览，Office 和 ZIP 只提供下载。预览类型使用核验后的 MIME。

## 读取与编辑

下表路径省略 `/api` 前缀，响应格式见[请求与联调](./架构与开发.md#请求与联调)。

| 方法与路径 | 用途 |
| --- | --- |
| `GET /courses/:id/contents` | 资料与问题统一列表 |
| `GET /materials/policy` | MIME 白名单、大小限制、有效期和登录要求 |
| `GET /materials/:id?version=1` | 资料介绍、默认或指定版本、版本选项及权限 |
| `PATCH /materials/:id` | 更新统一文件名、介绍和标签 |
| `GET /materials/:id/versions` | 现存版本分页，版本号降序 |
| `GET /materials/:id/versions/:version` | 指定版本元数据及当前统一文件名 |
| `DELETE /materials/:id/versions/:version` | 删除指定版本 |
| `GET/HEAD /materials/:id/versions/:version/preview` | 登录后读取可预览文件 |
| `GET/HEAD /materials/:id/versions/:version/download` | 登录后下载指定版本 |

统一列表支持 `kind=all|question|material`（默认 all）、`sort=active|newest|score`（默认 active）、完整标签 `tag`（最多30字符）。只有 `kind=question` 才能使用 `state=unresolved|solved` 或 `sort=score`，否则返回400。资料发布新版本会更新活跃时间。普通分页使用 `page`、`pageSize`、`total`，默认20条、最多50条。

资料列表项附带 `latestVersion`；详情还包含 `selectedVersion`、`versions` 和 `permissions`。详情中的版本选项为前50个现存版本及总数，更多历史通过版本列表继续加载；明确选中的版本会独立返回，不受第一页范围限制。`permissions` 包含 canEdit、canUploadVersion、canDeleteVersion、canManage、requiresLoginForFile。

版本 DTO 包含 version、size、mime、uploadedBy、createdAt、previewKind、previewUrl、downloadUrl。文件 URL 指向受控 Worker 入口，游客知道地址仍无法读取文件。`GET /me/activity?kind=material` 同样附带最新版本摘要。

资料删除复用 `DELETE /contents/:id`，评论、举报和整份资料下架复用通用内容接口。资料编辑复用通用编辑逻辑，省略字段保持原值，只有文件名、介绍或标签实际改变才更新 editedAt。

文件响应流式传输，禁用缓存，设置可信 MIME、统一文件名、ETag、Last-Modified 和 Accept-Ranges。GET 支持单段 Range、If-Range、If-None-Match；HEAD 不返回文件体。权限和可见性检查先于条件响应，下架后范围请求与304入口同样不可用。无效范围返回416，不支持预览的类型返回415。

## 上传协议

用户只进行一次发布操作，浏览器内部完成申请、PUT、确认三个阶段。申请上传须带 Idempotency-Key。

首次上传使用 `POST /material-uploads`：

```json
{
  "mode": "create",
  "courseId": "课程ID",
  "title": "高数讲义.pdf",
  "body": { "type": "doc", "content": [{ "type": "paragraph" }] },
  "tags": ["期末"],
  "file": { "size": 12345, "type": "application/pdf" }
}
```

后续版本使用同一接口，传 mode=version、materialId、file，不传标题或原始文件名。首次标题可由前端用本地文件名预填。标签可省略或为 null，最多8个。介绍遵循共享富文本契约，请求体上限384 KiB。

`material_upload_sessions.creation_draft` 以 JSON 文本暂存首次发布的标题、介绍和标签；增版会话为空，发布、取消或过期清理后清空。

申请成功返回201及 `{data: {uploadId, status: "pending", url, headers, expiresAt}}`。浏览器将原始 File/Blob 作为 PUT 请求体并附上票据 headers，不使用 multipart/form-data。云端签名绑定 Content-Type 和 Content-Length；长度由浏览器自动发送，前端不要手工设置 Content-Length。默认单文件上限100 MiB，MATERIAL_MAX_BYTES 可配置为1字节到100 MiB。

PUT 成功后调用 `POST /material-uploads/:id/confirm`，无需请求体和新的幂等键，成功返回 `{data: {materialId, version}}`。重复确认返回同一版本，积分只由原有触发器产生一次。`GET /material-uploads/:id` 返回 pending、confirming、published、cancelled、expired 状态和可空 result，仅上传者可访问。

上传地址有效10分钟，会话有效24小时。未结束的会话可用相同请求和 Idempotency-Key 重试申请，刷新上传地址；请求内容不同则返回409。已发布时重复申请返回 published 状态与 result，业务适配器应直接采用已有结果，不再次 PUT。

确认处理持有5分钟租约。并发确认返回 `409 UPLOAD_BUSY` 时查询状态或稍后重试；租约过期后允许接管。文件未传完、实际大小不符、类型不符分别返回 UPLOAD_INCOMPLETE、UPLOAD_SIZE_MISMATCH、UPLOAD_TYPE_MISMATCH，不产生资料或版本。文件类型检查魔数，Office ZIP 容器不做格式转换。

确认先将核验通过的临时对象封存到只能首次写入的正式对象，再在同一 D1 batch 中创建资料/版本、推进版本计数、记录发布结果和触发积分。D1 失败可复用已封存文件重试；提交成功但响应丢失不会删除文件或重复加分。最终事务重新检查身份、资料状态和维护权限。

`DELETE /material-uploads/:id` 取消未发布任务，正在确认或已发布时返回409。取消与过期任务由清理任务回收；已发布资料使用内容管理接口维护。

## 版本管理与清理

`DELETE /materials/:id/versions/:version` 允许资料作者、当前课程教师和管理员删除版本，返回 `{data: {materialId, version, deleted: true}}`；版本不存在或已删除返回404。版本不再有独立下架、恢复接口、状态或审查记录。资料整体下架继续使用通用内容接口，并关闭全部版本的公开入口。

版本删除在同一 D1 事务中记录积分操作者、删除版本、撤回对应原积分并更新资料活跃时间；不改写介绍的 editedAt。旧链接立即失效，默认回退到最新现存版本，删空后仍可查看资料介绍和评论。版本号不复用，重复确认原上传只返回历史发布结果，不会重新创建已删除版本。

管理者可通过 `GET /moderation/materials/:id/versions` 读取资料的现存版本，包括整体下架资料的版本。整体下架时仍可按维护权限删除版本；资料已删除则不能再维护版本。

版本删除提交后立即尝试移除对应 R2 正式文件；R2 暂时失败不恢复数据库记录，后续清理任务重试。Worker scheduled handler 每小时处理最多100个会话：先过期无人持有有效租约的任务，再清理已超过会话有效期1小时的临时对象，以及没有任何版本引用的正式对象（包括已删除版本的文件）。已清理会话隔日复查，回收较晚完成的 PUT。范围只涉及 materials/staging/ 与 materials/objects/，保留仍被版本引用的对象和上传幂等结果，不处理头像。

## 本地与云端

本地共用同一上传会话、核验和发布流程。票据 PUT 指向 `/api/local/material-uploads/:id/file`，要求上传者 Cookie、同源 Origin，且只在 APP_ENV=local 开放。传输适配以有界缓冲写入模拟 R2，不需要云端凭据。

production 使用 S3 预签名 PUT，aws4fetch 显式启用 allHeaders，将大小、类型纳入签名；桶保持私有。所需 Worker 变量、桶 CORS 和清理任务配置见[部署与运维](./部署与运维.md#域名与-r2-cors)，缺少配置时上传申请返回503。参考 [R2 预签名说明](https://developers.cloudflare.com/r2/api/s3/presigned-urls/) 和 [Workers R2 API](https://developers.cloudflare.com/r2/api/workers/workers-api-reference/)。

相关迁移及其升级检查见[数据库结构与迁移](../backend/README.md#数据库结构与迁移)。
