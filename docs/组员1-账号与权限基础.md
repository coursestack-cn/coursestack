第二阶段已完成账号管理、个人资料及学籍维护、管理员重置成员密码后端，最新字段、接口和限制见[账号管理与资料接口](./组员1-账号管理与资料接口.md)。以下保留基础结构说明，新增约定以该接口文档为准。

## 数据约定

所有业务 ID 为不透明字符串；HTTP 建号生成 UUID，不把学工号用作公开 ID。时间戳采用 Unix 秒。学工号去掉首尾空白、按字符串保存以保留前导零，区分大小写；不假设学校编号只含数字。2026-10-27 操作人确认：普通账号只能是学生或教师，管理员为独立身份。当前由 accounts.role 保存单个身份，API 返回 role。切换身份生成新 ID，旧身份以“已删除”占位，全部业务数据仍引用旧 ID；删除账号同样保留业务数据。历史多身份账号需先确认处理，迁移不会自动选择或删除角色。

| 表 | 职责和约束 |
| --- | --- |
| `accounts` | ID、昵称、单一身份、状态、学工号、密码散列、改密要求、凭据版本、data_generation、姓名、院系、专业、年级、头像和时间；完整字段见账户接口文档 |
| `account_audit` | 操作者、目标、动作、修改字段名及时间；身份退役后保留 |
| `sessions` | 仅存随机会话令牌的 SHA-256 摘要、账号、凭据版本及过期时间 |
| `login_attempts` | 摘要化限流键、计数、到期时间；不保存原始 IP 或学工号 |
| `courses` | 长期课程；0007 追加编号、简介、管理及加分配置字段，详见组员3联调说明 |
| `terms` | 学期 ID、显示名称及 current（0/1）；唯一索引限制至多一个当前学期，不预设校历日期 |
| `enrollments` | 课程＋学期＋账号复合主键，account_id 引用 accounts；按 role 区分师生，触发器保证每个实例恰好一位教师，学生可为零；不保存关系创建时间 |

管理员初始化是启用系统的前置步骤：初始空数据库没有可登录管理员，交互命令原子建立唯一管理员及凭据；重复或并发初始化不得产生第二个管理员，不覆盖已有密码。HTTP 不提供管理员创建、删除或降级入口。直接数据库维护仍属于可信运维范围。

本地与远程初始化、外部重置和状态查询已提供独立命令，详见[管理员初始化与恢复](./组员1-管理员初始化与恢复.md)。远程操作使用 Cloudflare D1 权限，管理员密码继续保存在数据库散列中；外部重置撤销旧会话，不增加匿名 HTTP 重置入口。

授课和修读已合表，与主动关注分别记录，也不限制共享内容的浏览。仅允许新建当前学期课程实例；新课程必须同时创建教师关系，不能存在完全没有教师的课程。教师行先于 courses 插入，在同一 D1 batch 中用 `PRAGMA defer_foreign_keys=ON` 延迟外键检查，courses 插入触发器会检查当前学期教师。管理员建课必须传 teacherId，教师建课由本人任教。

更换教师使用一次 UPDATE 修改原教师行的 account_id，不能先删后加；有学生时禁止删除唯一教师，即使没有学生，也不能删除整门课程最后的教师关系。删除账号或切换身份仍保留旧 ID 的历史关系和 teacher/student 角色；已删除教师行可保留关联，但不授予任何管理权限，新关系不能指向已删除账号。

切换当前学期时，在同一事务中先将旧 current 清零，再将新 current 置一；历史关系原样保留，权限只匹配 current=1。空库可暂不配置当前学期，此时禁止建课且不授予当前教师学籍权限。自动切换时间、名单修改与审计接口尚待完成。0012 迁移会拒绝旧库中的多教师、无教师课程或无教师的学生名单，不能直接丢弃冲突关系。

## HTTP 接口

统一成功响应 `{ "data": ... }`，失败响应 `{ "error": { "code": "...", "message": "..." } }`；响应均禁止缓存。没有公开注册。以下账号写请求需要同源 Origin，JSON 请求体上限 8 KiB。

| 方法、路径 | 输入／权限 | 成功返回 |
| --- | --- | --- |
| `GET /api/health` | 匿名 | status、environment、database |
| `POST /api/auth/login` | schoolNumber、password | id、nickname、role、mustChangePassword；设置会话 Cookie |
| `POST /api/auth/admin/login` | 仅 password | id、nickname、role、mustChangePassword；设置会话 Cookie |
| `GET /api/auth/me` | 有效会话（含待改密） | id、nickname、role、mustChangePassword |
| `POST /api/auth/logout` | 可重复调用 | loggedOut；清除 Cookie 并撤销当前会话 |
| `POST /api/auth/password` | 有效会话；oldPassword、newPassword | passwordChanged；清除 Cookie，所有旧会话失效 |
| `POST /api/admin/accounts` | 管理员会话；role、schoolNumber、nickname、password；student 还需要 name | 201；账号完整详情 |

管理员建号 `role` 只接受 student 或 teacher。accounts 和审计通过 D1 batch 原子写入，学工号冲突返回 409 且不留下半成品账号。学生须填姓名，教师可选；院系、专业、年级均可选，完整 DTO 见账户接口文档。管理员响应中的学工号不能复用为公开作者资料。

主要错误：400 输入错误，401 未登录／凭据无效，403 来源或权限不足，405 方法不支持（附 Allow），409 重复学工号／身份已退役，413 请求体过大，415 非 JSON，429 尝试次数过多。未知数据库错误返回通用 500，不返回 SQL、散列或内部异常。

当前密码技术策略：用户自行设置的新密码至少 8 个 Unicode 字符；登录、旧密码校验、管理员建号／重置、受信任的数据准备允许非空短密码。所有路径保留 UTF-8 不超过 72 字节的限制，不裁剪密码空白；bcrypt cost=12、独立随机盐。上线前需结合 Workers 实际套餐验证密码散列 CPU 成本；目前仅完成本地验证。

会话有效期 7 天，不滚动续期；256 位随机令牌只通过 HttpOnly Cookie 交给浏览器，HTTPS 下 Secure，SameSite=Strict。请求准入时校验账号状态、到期时间和凭据版本；改密原子提升版本，因此并发旧密码登录也不能获得可用的新会话。登录与 me 返回 mustChangePassword。标记为 true 的会话可查询登录状态、退出和改密，受保护接口返回 403 PASSWORD_CHANGE_REQUIRED；课程／讨论中间件同样拦截待改密会话。新密码不能与临时密码相同，改密成功清除标记并注销所有会话。当前密码错误返回 400 INVALID_CURRENT_PASSWORD，保留现有会话供纠正输入。

登录按来源 IP 每 15 分钟最多 50 次、按学工号／管理员入口最多 10 次，成功和失败均计数；改密每账号 15 分钟最多 10 次。local 共用本地来源桶。计数通过数据库原子更新，过期数据在成功登录时清理。云端限流、分布式攻击与监控策略仍需部署阶段验证。

## 其他模块如何接入

- 组员 2：对接上述两个登录入口和个人会话接口；初始密码可直接登录。浏览器通过同源 `/api` 调用，具体代理要求见[后端 README](../backend/README.md#前端联调)。已有账号列表、密码重置与用户改密页面；完整资料及身份管理界面另行对接。
- 组员 3：课程外键引用 `courses.id`；扩展课程编号、简介等字段时追加迁移。教师关系查询使用 `isCurrentCourseTeacher`；管理员判断使用 `isAdministrator`。这些函数不决定采纳、加分或内容状态的全部规则。
- 组员 4：上传者、收藏者等引用 `accounts.id`；主动关注另建表，不写入 `enrollments`。下载还需自行检查资料及具体文件版本状态，不因登录或关注而绕过下架限制。
- 所有后端：先通过 `requireSession(DB, request)` 取得服务端身份，再调用权限助手；不能将 body、查询参数或自定义请求头里的用户 ID 当成当前操作者。公开作者使用 `getPublicProfile` 的字段白名单。写入核对准入快照的 dataGeneration，旧身份退役后拒绝写入；普通会话撤销不取消已获准请求。

教师获取学籍使用 `getStudentRecordForTeacher(db, actorId, courseId, studentId)`：同一 SQL 查询验证操作者有效、当前学期授课和目标学生同课程同学期修读，再只返回 accountId、schoolNumber、name、department、major、grade（来自 accounts，无独立学籍表）；权限不足或目标不存在均返回 null。匿名、学生、历年教师、其他课程教师均不可读取。管理员另用 `getStudentRecordForAdministrator`，管理员身份不自动冒充课程教师。
