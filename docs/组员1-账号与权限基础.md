# 组员 1：账号与权限基础

本文件记录基于 main 四份提案的第一阶段实现与联调约定。原提案未定事项继续保持待定。2026-10-24 操作人明确：普通成员使用学号／工号与密码登录；管理员有且只有一个，单独入口只需密码；首次登录不强制改密。

第二阶段已完成账号管理、个人资料及学籍维护、邮箱验证和找回密码后端，最新字段、接口和限制见[账号管理与资料接口](./组员1-账号管理与资料接口.md)。以下保留基础结构说明，新增约定以该接口文档为准。

## 当前交付

- 本地后端环境、版本化 SQL 迁移与 Drizzle schema。
- 账号、身份、公开名称和私有学籍的分离；按学期记录授课和修读关系。
- 普通成员和唯一管理员登录、退出、查询自身身份、凭原密码修改密码。
- 管理员建立学生或教师账号；学生真实姓名和学号仅进入受控学籍表。
- 可复用的服务端权限查询，以及 D1 约束、隐私、会话和事务回归测试。

这不是组员 1 全部工作的完成声明，管理页面和名单导入尚未实现。

## 数据约定

所有业务 ID 为不透明字符串；HTTP 建号生成 UUID，不把学工号用作公开 ID。时间戳采用 Unix 秒。学工号去掉首尾空白、按字符串保存以保留前导零，区分大小写；不假设学校编号只含数字。当前成员建号只授予一种身份，角色关联表为未来受控身份维护保留空间。

| 表 | 职责和约束 |
| --- | --- |
| `accounts` | 不透明 ID、公开名称、状态、创建及最近登录时间；不含真实姓名和学工号 |
| `account_roles` | student / teacher / admin；部分唯一索引确保全库最多一个 admin |
| `student_records` | 学生真实姓名和唯一学号；复合外键保证账号有 student 身份 |
| `credentials` | 私有学工号和密码散列；学工号全库唯一，管理员为 NULL；version 用于撤销旧会话 |
| `sessions` | 仅存随机会话令牌的 SHA-256 摘要、账号、凭据版本及过期时间 |
| `login_attempts` | 摘要化限流键、计数、到期时间；不保存原始 IP 或学工号 |
| `courses` | 长期课程 ID、名称、创建时间；只是组员 3 业务表的最小基础 |
| `terms` | 学期 ID 和显示名称，不预设校历日期 |
| `academic_settings` | 单行当前学期指针；未配置时不授予当前教师学籍权限 |
| `teaching_assignments` | 课程＋学期＋教师唯一；复合外键保证 teacher 身份 |
| `enrollments` | 课程＋学期＋学生唯一；复合外键保证 student 身份 |

管理员初始化是启用系统的前置步骤：初始空数据库没有可登录管理员，交互命令原子建立唯一管理员及凭据；重复或并发初始化不得产生第二个管理员，不覆盖已有密码。HTTP 不提供管理员创建、删除或降级入口。直接数据库维护仍属于可信运维范围。

授课和修读不与主动关注共表，也不限制共享内容的浏览。切换当前学期指针后，旧关系原样保留；权限查询只匹配新指针。自动切换时间、退课及撤销授课的审计规则尚待确定。

## HTTP 接口

统一成功响应 `{ "data": ... }`，失败响应 `{ "error": { "code": "...", "message": "..." } }`；响应均禁止缓存。没有公开注册。写请求需要同源 Origin，JSON 请求体上限 8 KiB。

| 方法、路径 | 输入／权限 | 成功返回 |
| --- | --- | --- |
| `GET /api/health` | 匿名 | status、environment、database |
| `POST /api/auth/login` | schoolNumber、password | id、publicName、roles；设置会话 Cookie |
| `POST /api/auth/admin/login` | 仅 password | 唯一管理员身份；设置会话 Cookie |
| `GET /api/auth/me` | 有效会话 | id、publicName、roles |
| `POST /api/auth/logout` | 可重复调用 | loggedOut；清除 Cookie 并撤销当前会话 |
| `POST /api/auth/password` | 有效会话；oldPassword、newPassword | passwordChanged；清除 Cookie，所有旧会话失效 |
| `POST /api/admin/accounts` | 管理员会话；role、schoolNumber、publicName、password；student 还需要 realName | 201；id、publicName、role、schoolNumber |

管理员建号 `role` 只接受 student 或 teacher。账号、身份、凭据和学生学籍通过 D1 batch 原子写入，学工号冲突返回 409 且不留下半成品账号。真实姓名暂仅收集学生的姓名；教师其他私有资料尚未设计。管理员响应中的学工号不能复用为公开作者资料。

主要错误：400 输入错误，401 未登录／凭据无效，403 来源或权限不足，405 方法不支持（附 Allow），409 重复学工号／会话变化，413 请求体过大，415 非 JSON，429 尝试次数过多。未知数据库错误返回通用 500，不返回 SQL、散列或内部异常。

当前密码技术策略：不少于 12 个字符，UTF-8 不超过 72 字节，不裁剪密码空白；bcrypt cost=12，独立随机盐，无默认密码。策略可后续调整，并非原提案已有要求。上线前需结合 Workers 实际套餐验证密码散列 CPU 成本；目前仅完成本地验证。

会话有效期 7 天，不滚动续期；256 位随机令牌只通过 HttpOnly Cookie 交给浏览器，HTTPS 下 Secure，SameSite=Strict。数据库查询同时校验账号状态、到期时间和凭据版本；改密原子提升版本，因此并发旧密码登录也不能获得可用的新会话。首次登录不返回强制改密标记。

登录按来源 IP 每 15 分钟最多 50 次、按学工号／管理员入口最多 10 次，成功和失败均计数；改密每账号 15 分钟最多 10 次。local 共用本地来源桶。计数通过数据库原子更新，过期数据在成功登录时清理。云端限流、分布式攻击与监控策略仍需部署阶段验证。

## 其他模块如何接入

- 组员 2：对接上述两个登录入口和个人会话接口；初始密码可直接登录。浏览器通过同源 `/api` 调用，具体代理要求见[后端 README](../backend/README.md#前端联调)。管理页面尚未创建，也不假设现有前端框架。
- 组员 3：课程外键引用 `courses.id`；扩展课程编号、简介等字段时追加迁移。教师关系查询使用 `isCurrentCourseTeacher`；管理员判断使用 `isAdministrator`。这些函数不决定采纳、加分或内容状态的全部规则。
- 组员 4：上传者、收藏者等引用 `accounts.id`；主动关注另建表，不写入 `enrollments`。下载还需自行检查资料及具体文件版本状态，不因登录或关注而绕过下架限制。
- 所有后端：先通过 `requireSession(DB, request)` 取得服务端身份，再调用权限助手；不能将 body、查询参数或自定义请求头里的用户 ID 当成当前操作者。公开作者使用 `getPublicProfile` 的字段白名单。

教师获取学籍使用 `getStudentRecordForTeacher(db, actorId, courseId, studentId)`：同一 SQL 查询验证操作者有效、当前学期授课和目标学生同课程同学期修读，再只返回 accountId、studentNumber、realName；权限不足或目标不存在均返回 null。匿名、学生、历年教师、其他课程教师均不可读取。管理员另用 `getStudentRecordForAdministrator`，管理员身份不自动冒充课程教师。
