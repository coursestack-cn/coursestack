# 协作分工

文档和代码按主题组织，各主题负责人维护接口、实现和验证。成员编号用于明确主责与分支命名，不作为文档目录。

| 主题 | 主责 | 范围 |
| --- | --- | --- |
| 数据与账号权限 | 组员 1 | 数据库总体设计、账号会话、身份权限、授课修读、名单与学期管理，以及管理端所需接口 |
| 前端与交互 | 组员 2 | 全部主站、课程管理和管理端页面；公共组件、路由、上传预览、编辑器、状态与错误反馈 |
| 课程与讨论 | 组员 3 | 课程信息、问答评论、投票采纳、课程加分、讨论内容管理及事件供数 |
| 资料与信息服务 | 组员 4 | 资料与版本、上传预览下载、关注收藏、搜索通知及资料管理 |

数据库总体设计由组员 1 协调，各业务负责人实现自己的查询、写入和业务校验。网络运维由操作人统筹 Cloudflare 资源、开发与生产环境、部署及运行维护。

## 交叉边界

| 功能 | 约定 |
| --- | --- |
| 课程与成员 | 账号权限模块维护学期和成员；课程创建同步写入当前教师关系；主动关注独立于正式修读 |
| 文件引用 | 前端将链接写入 ProseMirror JSON 正文，资料模块提供页面所需接口；不保存问题与版本的数据库关联 |
| 资料评论 | 评论与回复归讨论模块；资料元数据、文件及版本状态归资料模块，共用内容模型 |
| 搜索与通知 | 各业务模块提供字段、事件、可见性和触发对象；信息服务实现消费、存储、游标、去重及查询 |
| 举报与下架 | 资料和文件归资料模块，问答评论归讨论模块；共同维护下架后的列表、搜索及文件访问一致性 |
| 管理页面 | 前端统一实现，账号、课程、资料等后端按业务归属提供接口 |

共享结构或接口变更前核对相关模块，说明字段、权限、状态、分页、错误码及并发行为的影响，并更新对应主题文档。未确认的业务规则明确标记，不自行补成结论。

## 开发与验收

- 分支、提交、PR 和敏感信息处理遵循 [Agent 协作约定](../AGENTS.global.md)；日常工作不直接向 `main` 提交或推送。
- 各模块执行相关静态检查或定向测试，记录实际结果与未验证范围，不运行完整构建；临时验证材料放在被忽略的 `.local/`。
- 联调按完整流程核对：建立账号、导入名单、上传资料、引用版本提问、回答采纳与计分、通知、版本更新和学期切换。
- 云端发布见[部署与运维](./deploy-dev.md)，本地测试结果不代表线上验证完成。
