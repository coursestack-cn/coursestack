# 账号与权限

账户基本信息统一保存在 `accounts`，普通成员只有 student 或 teacher 一种身份，admin 独立且全库至多一个。没有公开注册；管理员通过[运维命令](./管理员操作.md)初始化，再建立师生账号。

## 账户字段与隐私

ID 是不透明 UUID，切换身份时生成新 ID；学工号不能用作公开 ID。数据库字段用 snake_case，HTTP 用 camelCase，时间为 Unix 秒。

| 数据库字段 | 约束与用途 | HTTP 字段 |
| --- | --- | --- |
| `id` | TEXT 主键，不复用旧身份 ID | id |
| `nickname` | 可空；有值时去首尾空白后 1–80 字符，公开昵称 | nickname |
| `role` | student / teacher / admin | role |
| `status` | active / disabled / deleted | status |
| `school_number` | 非管理员登录标识；去首尾空白，保留前导零、区分大小写；未删除账号间唯一，管理员为 null | schoolNumber |
| `password` | bcrypt 散列；null 表示未开通登录或身份已删除 | 不返回 |
| `must_change_password` | 默认 false，要求登录后先改密 | mustChangePassword |
| `credential_version` | 正整数，默认 1；用于会话准入 | 不返回 |
| `name` | 可空，最多 80 字符；学生必填姓名和学号 | name |
| `department`、`major` | 可空，各最多 120 字符 | department、major |
| `grade` | 可空，最多 40 字符 | grade |
| `avatar_key` | 可空，当前头像 R2 键 | avatarUrl，使用 Worker 地址 |
| `created_at`、`last_login_at` | 创建时间非空，最近登录时间可空 | createdAt、lastLoginAt |

昵称、姓名、院系、专业、年级的空字符串保存为 null。完整账号详情包含上述可返回字段，仅本人和管理员可读取；公开 DTO 只包含 `id`、`nickname`、`avatarUrl`、`isDeleted`，展示时应处理昵称为空。没有邮箱、roles 数组、账户 revision、账户审计表或独立学籍表；当前不提供教师学籍查询接口。

其他表引用 `accounts.id`。公开作者使用 `getPublicProfile` 字段白名单；不能把管理端响应直接用于公开展示。已删除作者显示“已删除”、无头像、不再显示教师标识。

## 登录与会话

账号 JSON 请求体上限 8 KiB，写请求要求同源 Origin；成功返回 `{data: ...}`，失败返回 `{error: {code, message}}`，响应禁止缓存。

| 方法、路径 | 输入 | 成功返回 |
| --- | --- | --- |
| `POST /api/auth/login` | schoolNumber、password | id、nickname、role、mustChangePassword，并设置 Cookie |
| `POST /api/auth/admin/login` | password | 同上 |
| `GET /api/auth/me` | 有效会话，允许待改密状态 | 当前身份 |
| `POST /api/auth/logout` | 可重复调用 | loggedOut，撤销当前会话并清除 Cookie |
| `POST /api/auth/password` | oldPassword、newPassword | passwordChanged，撤销全部会话并清除 Cookie |

会话有效期 7 天，不滚动续期，允许多设备并存。256 位随机令牌通过 `coursestack_session` Cookie 传递，数据库仅存 SHA-256 摘要。Cookie 为 HttpOnly、SameSite=Strict，HTTPS 下加 Secure，不设置 Domain。普通业务不接受 Bearer 用户身份。

密码使用 bcrypt cost=12 和独立随机盐。用户自行设置的新密码至少 8 个 Unicode 字符；登录、旧密码校验、管理员建号及重置允许非空短密码。所有路径均限制 UTF-8 最多 72 字节，不裁剪密码空白。云端散列 CPU 成本仍需验证。

登录每 15 分钟按来源 IP 最多 50 次、按学工号或管理员入口最多 10 次，成功与失败均计数；改密每账号每 15 分钟最多 10 次。local 共用本地来源桶。限流键摘要化保存，不记录原始 IP 或学工号；过期计数在成功登录时清理，云端限流与监控仍待验证。

## 账号管理接口

以下接口仅管理员可用，JSON 对象拒绝未声明字段。

| 方法、路径 | 输入与行为 |
| --- | --- |
| `GET /api/admin/accounts` | page、pageSize、role、status、q；排除已删除身份 |
| `GET /api/admin/accounts/:id` | 返回未删除账号完整详情 |
| `POST /api/admin/accounts` | role、schoolNumber、password；学生必填 name；nickname、name、department、major、grade 可按角色选填；201 返回完整详情 |
| `PATCH /api/admin/accounts/:id` | 至少一个 nickname、status、role、schoolNumber、name、department、major、grade；仅修改提交字段，role 改变时替换身份 |
| `DELETE /api/admin/accounts/:id` | 标记删除身份，返回 id、deleted: true |
| `POST /api/admin/accounts/:id/password` | 可选 newPassword、mustChangePassword；重置成员密码 |

分页默认 page=1、pageSize=20，最大 100；role 可筛选 student / teacher / admin，status 可筛选 active / disabled。q 搜索昵称、学工号、姓名、院系、专业、年级，按创建时间倒序、ID 升序排列。

不能通过 HTTP 新增管理员，或禁用、删除、改变唯一管理员身份、为其设置学工号。学工号冲突返回 `409 SCHOOL_NUMBER_EXISTS`，账号事务整体回滚。

账户不使用 revision；同字段并发修改按最终写入顺序生效，不同字段不互相覆盖。状态、学工号更新及密码重置提升 `credential_version` 并撤销全部会话，仅修改个人资料不影响登录。

## 删除账户与切换身份

两者都保留全部业务记录，包括课程、历史关系、内容与文件版本、投票、采纳、积分流水、举报、内容审查和事件；后续关注、收藏、通知也须遵守。不会因作者删除自动下架内容、取消采纳或冲销积分。

旧账户保留 ID、原角色、创建时间和凭据版本，作为历史外键占位；设为 `status=deleted`，清空昵称、学工号、密码、受控资料、头像引用及最近登录时间，不允许登录或出现在账号列表。公开 DTO 将其昵称显示为“已删除”。

切换师生身份在一个 D1 batch 内创建新 UUID、复制基本信息，将旧身份标记删除并提升凭据版本、撤销会话，释放并转交学工号，再清空旧身份基本信息。任一步骤失败则整体回滚。

新账号保留昵称、姓名、院系、专业、年级、头像、密码、改密要求、创建／最近登录时间及 active / disabled 状态，本次提交的字段修改同时生效。返回完整新账号及 `previousId`，前端须使用新 ID，原会话重新登录。旧课程权限、修读资格、内容所有权及加分仍属于旧 ID，不转给新身份，也不按相同学工号继承。

删除账户不创建替代账号，并尝试立即清理无引用头像。旧学工号可以用于之后的新账号；历史授课、修读关系允许引用已删除身份，但不授予权限，新关系不能指向已删除账号。

## 请求准入与权限

请求入口校验会话、到期时间、凭据版本、active 状态、改密要求及角色，并保存服务端身份快照。普通退出、禁用、重置密码或会话到期阻止后续请求，不取消已经获准的请求。

业务写入 SQL 核对服务端身份 ID 仍存在且状态不是 deleted；身份标记删除后，旧请求不能继续写入。账户修改还要核对目标未删除，冲突返回 `409 ACCOUNT_DELETED`。不要接收客户端提供的操作者 ID 作为身份依据。

后端使用 `requireSession` 或讨论认证中间件取得身份，再检查具体课程、学期和内容状态；`isAdministrator`、`isCurrentCourseTeacher` 只提供身份与关系判断，不能代替业务规则。课程、内容和举报仍使用自身 revision，与账号修改规则不同。

## 本人资料与头像

| 方法、路径 | 权限与行为 |
| --- | --- |
| `GET /api/me/profile` | 登录，返回本人完整资料 |
| `PATCH /api/me/profile` | 登录，仅接受 nickname |
| `GET /api/profiles/:id` | 匿名，返回公开 DTO；禁用或不存在为 404 |
| `PUT /api/me/avatar` | 登录，上传图片原始二进制并替换头像 |
| `DELETE /api/me/avatar` | 登录，清除头像 |
| `GET /api/profiles/:id/avatar` | 匿名，读取当前有效头像；无头像、禁用或已删除为 404 |

头像支持 PNG、JPEG、WebP，最多 2 MiB，Content-Type 须匹配文件签名；不接受 SVG、远程 URL 或客户端 R2 键，不需要 If-Match。每次独立存储，只保留当前头像；角色切换保留正在使用的头像。

引用更新与读取被替换键在同一事务中完成，删除对象前复查已无账户引用。上传、更新和即时清理登记到 `waitUntil`，清理最多尝试三次；失败写入尝试删除新对象，清理失败不回滚已成功更新，接受少量残留对象。没有头像登记表、历史恢复或定时清理任务。头像通过 Worker 读取私有 R2，禁用缓存并设置 nosniff 与受限 CSP。

## 成员密码重置

普通成员忘记密码时，由管理员在系统外核实身份、重置并交付新密码；唯一管理员使用[外部恢复](./管理员操作.md)。

- `newPassword` 省略或空字符串时生成 24 位十六进制密码，仅在本次成功响应的 `generatedPassword` 返回；null 或非字符串为 400。明文不进入列表、审计、日志或前端持久存储。
- `mustChangePassword` 默认 false；管理界面的“要求用户重置密码”默认勾选。
- 登录与 me 返回该标记；为 true 时允许查询登录状态、退出和改密，受保护接口返回 `403 PASSWORD_CHANGE_REQUIRED`，课程讨论中间件同样拦截，前端进入 `/settings/password`。
- 强制改密不能沿用临时密码。当前密码错误返回 `400 INVALID_CURRENT_PASSWORD`，保留会话供纠正输入；成功后清除改密要求，注销全部会话。
- 重置与改密原子更新散列、凭据版本、改密标记和会话。重置同时清理成员登录与改密限流，保留共享 IP 限流，不保存密码明文。

常见错误还包括：401 未登录或凭据无效，403 来源或权限不足，405 方法不支持（附 Allow），413 请求体过大，415 非 JSON，429 限流；未知数据库错误返回通用 500，不泄露 SQL、散列或内部异常。
