# 前端路由

主站与管理端共用一个前端应用。下表约定浏览器页面地址，后端接口统一位于 `/api`，两者分开维护。新增地址时同步更新本文与 `frontend/src/lib/router/routes.ts`。

页面属性、请求状态、导航和权限接入见[页面接入约定](../frontend/src/pages/README.md)。

本文的课程管理入口已接入 2026-11-02 的目标契约：教师加入本学期已开设课程，按教学班管理学生和积分；管理员维护课程目录与学期开设安排，课程号即 id，完整规则见[课程与教学班目标设计](./课程与讨论.md#课程学期与教学班目标设计)。

## 路由机制

- 使用浏览器原生地址（History API），不使用 `#/` 形式的哈希路由。云端 Worker 对 `/api` 以外的未知路径回退到 `index.html`，Vite 开发服务器同样如此，见[部署与运维](./部署与运维.md)。
- 路由自行实现，不引入路由库，只覆盖以下功能：
  - 路径匹配与参数提取
  - 查询参数读写
  - 站内链接拦截
  - 前进、后退与滚动位置恢复
  - 按页面拆分代码、按需加载
- 路由在 `document` 上统一拦截同源链接点击，通用组件和正文中的站内链接都会自动走路由；通用组件仍只接收 `href` 或回调，不调用路由函数。
- 页面地址不得以 `/api` 开头，这一前缀保留给后端接口。
- 问题、回答、评论、资料路径中的内容 UUID 及回答、评论锚点统一使用 32 位小写十六进制，不带横杠；例如 `/questions/550e8400e29b41d4a716446655440000`。带横杠的旧内容地址通过 replaceState 规范化，保留查询参数和定位目标。内容路由参数在交给页面时还原为接口使用的 UUID；数据库和 API DTO 的 ID 不变。课程代码、学期 ID、教师账号 ID 和整数版本号保持原值，不根据字符串外观补上或移除横杠。

“登录”为“是”表示匿名访问跳转登录页；“否”表示可公开浏览，但发布、互动和下载仍需登录。接口归属见[协作分工](./协作分工.md)。

`:courseCode` 是唯一课程编号，例如 `/courses/MATH101`，路径段须经 `encodeURIComponent` 编码；课程列表、管理端课程链接和课程内导航统一使用编号，课程号不可通过普通编辑改写，保留 new 等普通课程号的浏览能力；创建入口统一使用 /manage/courses?new=1。页面直接读取 `GET /api/courses/:courseCode/entry`，不再查询内部 UUID。

全部课程列表始终进入课程公共页。公共页向已登录学生提供“修读学期”下拉框，只列本人修读过的学期；教师对应显示“授课学期”。选择后直接进入 `/courses/:courseCode/terms/:termId`，同时清除原页筛选与分页。学期页仍可选择本人其他学期或返回公共页，路径学期必须是该课程已安排开设的学期；公开信息不要求本人修读。教师和内容权限仍按服务端当前学期校验，不能由路径学期推导。

版本页的 `:versionId` 是整数版本号；该路径替换跳转到 `/materials/:materialId?version=整数`，省略查询参数则跟随最新现存版本。

未登录时，主导航不显示课程入口；登录后显示“全部课程”，指向 `/courses`，窄屏时收进账号菜单。品牌链接始终返回 `/`，账号菜单不提供“我的课程”。首页等待会话确认后切换内容，未登录首页与 `/courses` 复用全部课程页。

我的课程统一放在登录后的首页。`?tab=current`（默认，可省略）显示本学期，`?tab=history` 显示非当前学期的本人课程，`?tab=favorites` 显示收藏课程；其他值按本学期处理。使用 `page` 分页，本学期及历年每页 12 门、按课程编号排序，收藏每页 20 门、按收藏时间倒序。切换分类重置页码，超出结果范围时替换为最后一页。同一课程在历年列表中只出现一次并列出参与学期，也可以同时出现在本学期列表。正式关系的课程卡片只有一个参与学期时直达该学期页；有多个历史学期或来自收藏时进入公共页。首页下方的课程动态使用独立 `feedPage` 分页，范围不随课程分类切换。`/me` 本身不是页面，直接访问显示 404。

`/me/favorites` 使用 `type=course|material|question`（省略为全部）、`courseId` 和 `page` 筛选，切换类型或课程重置页码，每页 20 项。课程链接进入公共页，资料进入最新版本，问题进入整个讨论；不可用内容无跳转，保留取消收藏操作。收藏数据与在途请求按账号隔离，收藏变更及页面重新聚焦时刷新，支持同浏览器多标签页同步。

### 课程管理

课程管理页面依据服务端权限开放，无权限时显示“没有权限”状态。

教师账号菜单中的“管理课程”指向 `/manage/courses`；管理员账号菜单只提供“管理端”，默认进入 `/manage/accounts`。课程页标题旁的“管理课程”、加分规则弹窗中的“查看教学班”和管理列表中的“教学班”按身份进入：管理员进入 `/manage/courses/:courseCode/classes`；教学班由课程、学期和教师确定，教师在一门课程中至多管理本人当前学期的一个班，因此直接进入该班的学生名单。本学期未任教该课程的教师不显示“查看教学班”。管理员在管理页内按“账号管理、课程管理、学期设置、内容审查”的顺序切换，教学班及学生名单仍选中课程管理，教师不显示这组导航。教师课程列表只含本人当前学期授课的课程，管理员查看全部课程。

首页、全部课程页及管理页统一进入 `/manage/courses?new=1`：管理员打开新建课程弹窗，教师打开加入本学期课程弹窗。关闭后移除 new 参数，成功后留在管理列表并清除搜索与页码。表单行为见[课程管理接入](../frontend/src/pages/README.md#课程管理接入)。教学班列表、教学班学生名单各自使用独立页面；添加学生、调整积分和编辑加分规则使用小弹窗，积分流水是学生名单页面中的单独选项卡。开课安排继续在课程管理页操作，全站学期设置移至 `/manage/terms`。

| 地址 | 内容 | 登录 |
| --- | --- | --- |
| `/manage/courses` | 课程信息编辑、开课安排、教师加入及教学班入口；q 为课程名称或课程号，page 为页码，new=1 按身份打开创建或加入弹窗 | 是 |
| `/manage/courses/:courseCode/classes` | 管理员查看某课程的教学班列表、删除教学班。termId 筛选学期，page 为页码；教师访问时替换跳转到本人当前学期教学班的学生名单 | 是 |

教学班由课程号、学期 ID 和教师 ID 联合确定，没有单独的 classId。三个标识都在学生名单路径中，刷新、收藏或分享链接不会随着当前学期变化指向另一个班级。三个标识均按接口原值进行路径段编码，不改变格式；教师账号 ID 可能是带横杠 UUID，也可能是示例账号的 32 位字符串，不能互相转换。页面可直接通过班级详情接口加载，不依赖从列表传入临时数据。

教学班列表只供管理员使用，默认显示全部学期，可通过 termId 筛选。教师访问列表地址时，本学期任教该课程则替换跳转到本人教学班，否则提示本学期未任教或尚未设置当前学期。学生名单页通过服务端校验具体班级权限，管理员可查看历史班，教师不能访问其他教师或历史班的名单。历史班不提供添加学生入口。两页的面包屑与标题按课程、学期和教师命名，见[课程管理接入](../frontend/src/pages/README.md#课程管理接入)。浏览器后退恢复原列表的筛选和页码。旧管理概览、名单入口跳转时仅保留 termId 和 page。

### 其他

不匹配任何地址时显示 404 页面。业务页应区分 `404 CONTENT_UNAVAILABLE` 与未知地址；已删除的评论使用后端占位并保留已有回复；已删除的问题、资料、回答及下架内容对公众返回 404，显示不可用；所有者打开自己被下架的内容时显示私有维护视图，管理者通过内容审查入口查看。具体状态见[课程与讨论](./课程与讨论.md#内容文件引用与可见性)。

## 约定

### 查询参数

筛选、排序、分页都写入查询参数，保证后退可以回到原筛选，链接也可以直接分享。例如：

```text
/courses/MATH101?kind=question&state=unresolved&sort=active&page=2
/search?q=边界条件&type=question&course=12
```

各列表参数在实现页面时登记。

`/search` 使用 `q`、`type=all|course|material|question|answer`、精确课程号 `course`、标签关键词 `tag`、`sort=relevance|updated` 和 `page`，每页20条。关键词规范化后最多100字符、8个空白分隔词，取交集；标签最多30字符。提交查询或改变筛选/排序回到第1页，切换为课程类型时清除标签；清除筛选保留关键词和排序。刷新、前进和后退恢复参数，页码超界替换为最后一页。空关键词不请求结果；超长或不兼容条件显示错误，不悄悄截断。课程选择器复用课程列表接口。回答结果经既有 `/answers/:answerId` 路由定位到回答锚点；接口规则见[全站搜索](./全站搜索.md)。

课程页的 `bonus=history` 打开学生本人的加分历史弹窗；`bonusTerm` 为学期 ID，省略时查询全部学期，`bonusPage` 为 1–10000 的页码，每页 10 条，非法页码按第 1 页处理，超出结果范围时替换为最后一页。公共课程页的按钮默认打开全部学期，具体学期页的按钮默认选择该学期。学期切换清除 bonusPage，不影响资料与问答列表的筛选和分页。关闭弹窗移除 bonus 参数并保留历史筛选；刷新、前进和后退均从地址恢复。积分 toast 使用 `/courses/:courseCode?bonus=history&bonusTerm=:termId` 打开对应课程与学期；游客及非学生不展示个人历史。

全部课程页（`/courses` 及未登录首页）使用 `q` 搜索课程名称或编号，去首尾空白，最多 100 个字符；`page` 为 1–10000 的整数，省略或非法值按第 1 页处理。课程按编号升序排列，每页显示 12 门。提交或清除搜索回到第 1 页，翻页保留关键词；结果页码超出实际范围时替换为最后一页。

教学班列表、教学班学生名单与积分流水每页 20 条；page 和 ledgerPage 均为 1–10000 的整数，省略或非法值按第 1 页处理，超出结果范围时替换为最后一页。切换学期清除教学班页码，学生名单与流水分页互不影响，切换选项卡保留两者页码；刷新和前进、后退按地址恢复。列表页的 termId 仅用于筛选，学生名单路径中的 termId 则是班级身份的一部分。

课程统一列表的学期下拉框使用 `termId`：公共页省略时为全部学期，学期页省略时为路径指定的学期；显式 `?termId=` 表示全部学期，其他值按具体学期筛选。切换筛选只更新查询参数并清除 page，不切换课程学期或改变权限；刷新、前进和后退恢复所选条件。旧内容以及发布时未设置当前学期的内容仅出现在全部学期中。

课程统一列表使用 `kind=all|question|material`（默认 all）、标题关键词 `title`、标签关键词 `tag`、`page` 和 `sort=active|newest`，每页20条。只有筛选问答时显示 `state=all|unresolved|solved` 和 `sort=score`；切出问答会清除专用条件。标题关键词最多200字符、标签关键词最多30字符，去首尾空白后按连续子串匹配，ASCII 英文字母忽略大小写；标题包含关键词、任意一个标签包含关键词即满足对应条件，留空不筛选，两者同时填写时取交集。整个输入不拆词，`%`、`_` 按普通字符处理。标题和标签可在各自输入框内清空，点击“筛选”或按回车提交两项条件。刷新、前进和后退按地址恢复。旧列表入口保留标题、标签、排序与页码并替换跳转。改变筛选或排序回到第 1 页。问题详情的 `page` 为回答页码，每页 20 条；采纳答案优先，其余按净赞数排序。评论区独立分页与排序；回复其他评论的评论与被回复的评论同属一个评论区，另存被回复评论的引用。`/me/materials`、`/me/questions`、`/me/answers` 每页20条，数据来自 `/api/me/activity?kind=material|question|answer`。

课程统一列表另支持发布人 `authorId`，省略或前端空值为“全部”，单选后立即生效并清除 page，与学期、类型、状态、标题和标签取交集；切换其他筛选保留发布人。下拉框支持昵称搜索，固定保留“全部”，不提供单独清除发布人按钮。未选择时按钮显示“全部发布人”，选中后显示“发布人：昵称”。候选来自本课程全部学期的公开问题、资料，不随其他内容筛选缩减，按最近发布及账号ID稳定排序，每批20人并可加载更多。搜索仅查询候选，不写入网址；选定后按账号ID匹配，刷新和前进后退通过精确查询恢复昵称。重名、未设置昵称及已删除账号显示公开区分标识，不展示姓名、学号等受控信息；候选或已选项加载失败可重试，不自动切换“全部”，失去全部公开内容的已选发布人显示“发布人不可用”，原条件保留。旧资料、问题入口保留 authorId。

### 定位与中转

- 资料详情用 `?version=整数` 固定版本，省略时显示最新现存版本；切换版本只改查询参数，保留页面与评论草稿。
- 页面内的评论回复引用使用当前地址的 #comment-:commentId，保留已有查询参数，不经过中转页；直接评论问题、回答或资料说明时不显示回复引用。
- 回答和评论在页面内用锚点定位：`/questions/:questionId#answer-:answerId`、`#comment-:commentId`。打开后滚动到目标并短暂高亮。
- 只有回答或评论 ID 时，使用 `/answers/:answerId` 或 `/comments/:commentId`。前端沿 targetKind / targetId 逐级查出所属问题或资料，替换为带锚点的地址，不在历史记录中留下中转页。
- 通知、搜索结果、收藏和个人空间中的链接，统一指向本文件中的地址。

### 登录与权限

- 未登录打开“登录”一列为“是”的页面时，跳转到 `/login?next=<原地址>`；登录后返回 `next`。
- 跳转前校验 `next` 必须是以 `/` 开头的站内路径，且不以 `//` 开头，防止跳转到外站。
- 登录或恢复会话时 mustChangePassword 为 true，优先跳转到 `/settings/password`，忽略原 next；改密成功注销会话并回到对应登录入口。
- 前端的登录拦截只用于改善体验。是否为本课程教师、能否编辑等权限一律由服务端判断，前端按接口返回的 401、403 显示对应状态，不在路由中重复后端规则。

### 页面切换

每次切换页面时：

- 更新页面标题，格式为 `<页面标题> - 课栈`。
- 进入新页面时回到顶部，后退时恢复原滚动位置；带锚点时滚动到目标。
- 路径变化时默认聚焦新页面的主标题，方便读屏用户感知页面变化。从顶栏按 Enter 搜索时，焦点留在搜索框，可以继续输入关键词。

## 内容审查与通知

- `/manage/contents` 是管理者在授权课程范围内的统一入口；`/courses/:courseCode/manage/reports` 限定单门课程。课程标题旁提供“内容审查”入口，单门课程的审查页通过面包屑回到该课程的管理入口，管理员为教学班列表，教师为本人教学班。
- `tab=reports|contents` 切换举报处理与内容管理；`status` 对应举报状态或内容状态，内容管理还支持 `kind`；`page` 每页20条。`content` 选择审查原文，`report` 选择正在处理的举报。审查页只展示上下架与举报处理操作，资料文件通过专门审查入口预览。
- `/me/contents/:contentId` 是所有者维护入口，显示上下架理由，允许编辑或删除未删除内容；资料另可进入文件版本维护。个人列表包括未删除的下架内容，隐藏回答和评论中转到这个页面。所有者直接打开下架问题或资料也显示私有维护视图，不加载公开讨论。
- `/notifications?status=unread|read|all` 展示直接互动、采纳、管理、收藏更新和他人操作产生的积分通知，默认未读；每批最多20条，通过“加载更多”继续，不提供页码。点击查看或标记已读后更新服务端，已读历史仍可筛选查看；“全部已读”使用点击时当前列表最大 ID，不影响随后到达的事件。
- 页头在非通知页只轮询未读总数；通知页每次获取第一批，并复查已加载条目的阅读状态和可见性，未读数不变也刷新。每个可见标签页独立每60秒轮询，重新聚焦、恢复可见或联网时补查；账号切换沿用会话同步并清空旧状态，不增加通知跨标签页通信。
- 普通通知跳转内容，管理通知进入所有者维护页，积分通知进入对应课程、学期的加分历史。内容不可查看时仍保留通知，隐藏标题并允许标记已读；子内容解除下架限制但祖先仍隐藏时不显示“已重新上架”。申诉与复核联系通过外部沟通，不提供站内申请上架入口。
