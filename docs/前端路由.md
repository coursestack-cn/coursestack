# 前端路由

主站与管理端共用一个前端应用。下表约定浏览器页面地址，后端接口统一位于 `/api`，两者分开维护。新增地址先更新本文与 `frontend/src/lib/router/routes.ts`；登记地址不代表业务页已完成。

页面属性、请求状态、导航和权限接入见[页面接入约定](../frontend/src/pages/README.md)。

## 路由机制

- 使用浏览器原生地址（History API），不使用 `#/` 形式的哈希路由。云端 Worker 对 `/api` 以外的未知路径回退到 `index.html`，Vite 开发服务器同样如此，见[部署与运维](./deploy-dev.md)。
- 路由自行实现，不引入路由库，只覆盖以下功能：
  - 路径匹配与参数提取
  - 查询参数读写
  - 站内链接拦截
  - 前进、后退与滚动位置恢复
  - 按页面拆分代码、按需加载
- 路由在 `document` 上统一拦截同源链接点击，通用组件和正文中的站内链接都会自动走路由；通用组件仍只接收 `href` 或回调，不调用路由函数。
- 页面地址不得以 `/api` 开头，这一前缀保留给后端接口。
- 页面路径中的 UUID 及回答、评论锚点统一使用 32 位小写十六进制，不带横杠；例如 `/questions/550e8400e29b41d4a716446655440000`。带横杠的旧地址通过 replaceState 规范化，保留查询参数和定位目标。路由参数在交给页面时还原为接口使用的 UUID；数据库和 API DTO 的 ID 不变。课程代码和整数版本号不做此转换。

我的课程统一放在登录后的首页。`?tab=current`（默认，可省略）显示本学期，`?tab=history` 显示非当前学期的本人课程；其他值按本学期处理。使用 `page` 分页，每页 12 门，按课程编号排序，切换分类重置页码，超出结果范围时替换为最后一页。同一课程在历年列表中只出现一次并列出参与学期，也可以同时出现在本学期列表。关注课程接口尚未实现，暂不显示关注分类；动态区域暂不显示。`/me` 路由已移除，直接访问显示 404；其下资料、提问、回答与收藏页面的地址保持不变。

### 其他

不匹配任何地址时显示 404 页面。业务页应区分 `404 CONTENT_UNAVAILABLE` 与未知地址；已删除的评论使用后端占位并保留已有回复；已删除的问题、资料、回答及下架内容返回 404，显示不可用。具体状态见[课程与讨论](./课程与讨论.md#内容文件引用与可见性)，问答页面通过 `ContentState` 显示不可用状态，资料页面仍待接入。

## 约定

### 查询参数

筛选、排序、分页都写入查询参数，保证后退可以回到原筛选，链接也可以直接分享。例如：

```text
/courses/MATH101/questions?state=unresolved&sort=active&page=2
/search?q=边界条件&type=question&course=12
```

各列表参数在实现页面时登记。现有账号与课程讨论普通列表使用 page、pageSize、total；资料、搜索等未实现接口的筛选参数待对接。

全部课程页（`/courses` 及未登录首页）使用 `q` 搜索课程名称或编号，去首尾空白，最多 100 个字符；`page` 为 1–10000 的整数，省略或非法值按第 1 页处理。每页显示 12 门课程，按创建时间倒序排列。提交或清除搜索回到第 1 页，翻页保留关键词；结果页码超出实际范围时替换为最后一页。卡片展示简介与本学期教师，点击进入课程主页；教师和管理员可通过“新建课程”进入已有发布路由。

问答列表使用 `state=all|unresolved|solved`（默认 all）、`sort=active|newest|score`（默认 active）、完整 `tag` 和 `page`，每页 20 条。改变筛选或排序回到第 1 页。问题详情的 `page` 为回答页码，每页 20 条；采纳答案优先，其余按净赞数排序。评论区独立分页与排序，评论回复保持直接父级关系。本人提问、本人回答通过 `/api/me/activity?kind=question|answer` 获取，每页 20 条。

### 定位与中转

- 回答和评论在页面内用锚点定位：`/questions/:questionId#answer-:answerId`、`#comment-:commentId`。打开后滚动到目标并短暂高亮。
- 只有回答或评论 ID 时，使用 `/answers/:answerId` 或 `/comments/:commentId`。前端查出所属内容后替换为带锚点的地址，不在历史记录中留下中转页。当前接口返回直接父级 targetKind / targetId，中转页需沿父级查找所属问题或资料，不能依赖已删除的 questionId / replyToId 字段。
- 通知、搜索结果、收藏和个人空间中的链接，统一指向本文件中的地址。

### 登录与权限

- 未登录打开“登录”一列为“是”的页面时，跳转到 `/login?next=<原地址>`；登录后返回 `next`。
- 跳转前校验 `next` 必须是以 `/` 开头的站内路径，且不以 `//` 开头，防止跳转到外站。
- 登录或恢复会话时 mustChangePassword 为 true，优先跳转到 `/settings/password`，忽略原 next；改密成功注销会话并回到对应登录入口。
- 前端的登录拦截只用于改善体验。是否为本课程教师、能否编辑等权限一律由服务端判断，前端按接口返回的 401、403 显示对应状态，不在路由中重复后端规则。

### 页面切换

每次切换页面时：

- 更新页面标题，格式为 `<页面标题> - 课栈`。
- 进入新页面时回到顶部，后退时恢复原滚动位置；带锚点时滚动到目标。
- 焦点移到新页面的主标题，方便读屏用户感知页面变化。
