# 管理员操作

每个数据库只有一个管理员，密码以 PBKDF2 散列保存在 `accounts.password`，Worker 不读取管理员密码环境变量。网站内改密需要原密码；首次初始化或忘记密码时，使用 `backend/scripts/` 中的独立 Node.js 命令，不提供匿名恢复 HTTP 接口。

普通成员由管理员通过[成员密码重置接口](./账号与权限.md#成员密码重置)处理。以下命令在 `backend/` 的交互终端执行，只针对目标数据库的唯一管理员。

## 本地操作

首次先运行 `pnpm db:setup:local`，再按场景选择命令：

| 命令 | 行为 |
| --- | --- |
| `pnpm admin:init:local` | 首次设置密码，已初始化时拒绝覆盖 |
| `pnpm admin:status --local` | 查询管理员 ID、状态及凭据版本 |
| `pnpm admin:reset:local` | 重置已有管理员密码并撤销旧会话 |

也可使用 `pnpm admin:init --local`、`pnpm admin:reset --local`。本地固定使用 `wrangler.json` 的 local 环境与 `backend/.wrangler/state/v3`，显式关闭远程绑定。

密码输入两次且不回显，允许非空短密码，UTF-8 最多 72 字节；网站内自行改密的新密码至少 8 个字符。写入前分别要求输入 `INIT local` 或 `RESET local`，取消或输入不符时不写入。密码不通过参数、管道、环境变量或 SQL 文件提供，命令不读取已有测试密码文件。

## 远程操作

先准备采用当前结构的目标 D1，见[数据库初始化流程](../backend/README.md#数据库结构与迁移)。运维命令不创建数据库、升级旧结构或导入种子。

1. 核对目标 Account ID、D1 Database ID，并准备允许写入目标 D1 的 Cloudflare API Token。
2. 复制 `backend/scripts/admin-target.example.json` 到被忽略的 `backend/.local/admin-production.json`；只填 accountId 和 databaseId，不保存 Token、密码或个人资料。
3. 先查状态，再按需选择初始化或重置；不要把以下三条当作顺序执行的初始化流程。

```sh
pnpm admin:status --remote --config .local/admin-production.json
pnpm admin:init --remote --config .local/admin-production.json
pnpm admin:reset --remote --config .local/admin-production.json
```

命令显示账号 ID、数据库 ID 和管理员状态，不从当前 Worker 猜测目标。Token 通过终端隐藏输入或进程的 `CLOUDFLARE_API_TOKEN` 读取，不自动读取凭据文件或 Wrangler 登录缓存；管理员密码仍只支持交互输入。

写操作要求输入 `INIT <数据库 ID>` 或 `RESET <数据库 ID>`。远程直接访问 D1 REST API，不回退本地；缺少配置、参数冲突或使用占位 ID 时拒绝执行。

## 原子性与结果确认

初始化原子建立管理员及密码散列；已有唯一管理员但无密码时可补设，有密码时拒绝覆盖。唯一约束保证重复或并发初始化不会创建第二个管理员。

重置权限来自本地文件访问权或 Cloudflare D1 权限，不依赖旧密码或网站会话。在同一 batch 内核对管理员仍 active 且凭据版本未变，更新散列、递增 `credential_version`、清除改密要求、撤销全部管理员会话，并清理管理员登录和改密限流。

账号 ID、基本资料、头像及普通成员会话保持不变；共享 IP 限流不清除，已获准业务请求仍可完成。并发改密或重置使旧版本操作失败，不覆盖新密码；禁用或异常管理员数据不会自动修复。

命令返回管理员 ID，不保存账户审计记录。成功后用新密码重新登录，命令不会自动登录或绕过限流。

## 失败处理

| 情况 | 处理 |
| --- | --- |
| 已初始化 | 确需恢复时使用 reset，init 不覆盖密码 |
| 尚未初始化 | 使用 init，reset 不创建账号 |
| 凭据或状态变化 | 重新查 status，核对后重试 |
| Cloudflare 拒绝访问 | 检查目标 ID、Token 有效性和 D1 写权限 |
| 中断或结果不明 | 命令不自动重试；先查管理员状态及凭据版本，并尝试新密码，避免重复重置 |

终端只输出受控错误，不输出原始 SQL、异常或 Token。本地与模拟传输测试不代表真实远程操作已验证。
