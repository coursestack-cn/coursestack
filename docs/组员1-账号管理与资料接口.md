# 账号管理与资料接口

本文件记录 2026-10-27 确认的账户模型。账户基本信息统一保存在 `accounts`；师生身份只能二选一，管理员独立。删除账户或切换身份保留全部业务数据，旧作者显示为“已删除”。

## 账户字段

数据库字段使用 snake_case，HTTP 使用 camelCase。基本信息包括登录标识、密码、身份、个人资料、头像和账户时间；登录会话与下列业务记录分别管理。

| 数据库字段 | 属性与用途 | HTTP 字段 |
| --- | --- | --- |
| id | 非空 TEXT 主键，不透明 UUID；身份切换时生成新 ID，旧 ID 不复用 | id |
| nickname | 非空 TEXT，去首尾空白后 1–80 字符，公开昵称 | nickname |
| role | 非空 TEXT；student / teacher / admin；全库至多一个 admin | role |
| status | 非空 TEXT；active / disabled / deleted；deleted 是已退役身份 | status |
| school_number | 可空 TEXT；未退役账号间唯一，保留前导零、区分大小写；管理员为 NULL | schoolNumber |
| password | 可空 TEXT，仅存 bcrypt 散列；NULL 表示未开通登录或身份已退役 | 不返回 |
| must_change_password | 非空布尔值，默认 false；要求登录后先改密 | mustChangePassword |
| credential_version | 非空正整数，默认 1；会话准入时核对，改密、停用等操作递增并撤销会话 | 不返回 |
| data_generation | 非空正整数，默认 1；仅身份退役时递增，拦截旧身份已在途的写入 | 不返回 |
| name | 可空 TEXT，姓名最多 80 字符；学生必须有姓名和学号 | name |
| department | 可空 TEXT，院系最多 120 字符 | department |
| major | 可空 TEXT，专业最多 120 字符 | major |
| grade | 可空 TEXT，年级最多 40 字符，例如“2024级” | grade |
| avatar_key | 可空 TEXT，当前头像 R2 键 | avatarUrl，使用 Worker URL |
| created_at | 非空 INTEGER，创建时间，Unix 秒 | createdAt |
| last_login_at | 可空 INTEGER，最近登录时间，Unix 秒 | lastLoginAt |

不再提供邮箱、account revision、roles 数组、publicName、realName 或独立学籍表。姓名、院系、专业、年级为空字符串时保存为 NULL；它们属于账户基本信息，保持受控可见。

账号详情返回 id、nickname、role、status、schoolNumber、name、department、major、grade、avatarUrl、createdAt、lastLoginAt、mustChangePassword。仅管理员和本人可取得完整详情；公开作者必须使用专门的公开 DTO。

## 管理接口

成功响应为 `{data: ...}`，失败为 `{error: {code, message}}`。写请求要求同源 Origin；JSON 对象拒绝未声明字段。账户修改不需要 revision，头像不需要 If-Match。

| 方法、路径 | 输入 | 行为 |
| --- | --- | --- |
| GET /api/admin/accounts | page、pageSize、role、status、q | 分页列表，排除已退役身份 |
| GET /api/admin/accounts/:id | 管理员会话 | 未退役账号的完整详情 |
| POST /api/admin/accounts | role、schoolNumber、nickname、password；学生必填 name；可选 name、department、major、grade | 建立学生或教师账号 |
| PATCH /api/admin/accounts/:id | 至少一个 nickname、status、role、schoolNumber、name、department、major、grade | 仅修改提交的字段；role 发生变化时替换身份 |
| DELETE /api/admin/accounts/:id | 管理员会话 | 退役身份；返回 id、deleted: true |
| GET /api/admin/accounts/:id/audit | page、pageSize | 审计记录；旧身份退役后仍可按旧 ID 查询 |
| POST /api/admin/accounts/:id/password | 可选 newPassword、mustChangePassword | 重置成员密码 |

分页默认 page=1、pageSize=20，最大 100。role 为 student / teacher / admin，status 为 active / disabled；q 搜索昵称、学工号、姓名、院系、专业、年级。按创建时间倒序、ID 升序排列。

同字段并发修改按数据库最终写入顺序生效，不因客户端看到旧值而拒绝；不同字段互不覆盖。唯一学工号冲突返回 409 SCHOOL_NUMBER_EXISTS，整笔事务及审计一起回滚。不能禁用、删除、改变唯一管理员身份或为其设置学工号；不能通过 HTTP 新增管理员。

普通字段更新不改变 data_generation。状态或学工号更新、密码重置会提升 credential_version 并撤销该账号全部会话；只更新个人资料不影响登录。

## 删除账户与切换身份

两者都保留问题、回答、评论、资料和版本、课程、授课及修读关系、赞踩、采纳状态、加分流水、举报、审查记录、事件和审计。其他人的回答、评论和课程关系也全部保留；不会因作者退役自动下架内容、取消采纳或冲销加分。尚未实现的关注、收藏、通知模块也必须遵循此保留规则。

旧 accounts 行保留为外键所需的身份占位：status=deleted、nickname=“已删除”，清除学工号、密码、姓名、院系、专业、年级、头像引用及最近登录时间，不再允许登录或出现在账号列表。保留旧 ID、原角色、创建时间及内部版本，供历史记录引用。

身份切换接受已有任意学期授课、修读或内容的账号，返回完整的新账号详情及 previousId：

1. 在同一个 D1 batch 中创建新 UUID，复制基本信息并设置新 role；本次提交的其他基本字段同时生效。
2. 旧身份设为 disabled，提升 credential_version 和 data_generation，撤销全部会话。
3. 旧身份转为 deleted，释放学工号；新账号承接学工号和密码，旧身份清除个人资料。整个事务一起提交或回滚。

新账号保留昵称、姓名、院系、专业、年级、头像、密码及改密要求、创建／最近登录时间和 active / disabled 状态；只有身份与 ID 改变，或按本次提交修改指定字段。其业务记录从零开始，原业务记录继续属于旧 ID。旧授课关系、修读资格、内容所有权和加分不会变成新身份的权限或个人记录。前端使用返回的新 id 更新列表及后续请求，原会话须重新登录。

删除账户只执行旧身份退役，不创建新账户，并立即尝试清理已无引用的头像。同一学工号可以用于此后新建账户，新账户仍不接管旧 ID 的业务数据。

## 请求准入与事务

请求入口校验会话、到期时间、credential_version、账号 active 状态、强制改密要求和角色。通过后保存服务端身份快照。普通退出、禁用、密码重置或到期只拒绝后续请求，不取消已获准的请求。

业务写入 SQL 核对请求快照中的账号 ID 和 data_generation；身份退役后，旧请求不能继续新增或修改业务数据。账户写入同样核对目标尚未退役，冲突返回 409 ACCOUNT_RETIRED。课程、学期、内容可见性等业务条件仍由对应写入检查。无需固定等待五秒，也不把 data_generation 交给前端传入。

账户事务使用 D1 batch 完成修改与审计。课程、内容和举报自身的 revision 继续保留，与已移除的 accounts.revision 无关。

## 本人资料与公开资料

| 方法、路径 | 权限及输入 | 返回／行为 |
| --- | --- | --- |
| GET /api/me/profile | 登录 | 本人完整资料 |
| PATCH /api/me/profile | 登录；nickname | 仅修改昵称 |
| GET /api/profiles/:id | 匿名 | id、nickname、avatarUrl、isDeleted；禁用或不存在返回 404 |
| PUT /api/me/avatar | 登录；图片原始二进制 | 替换当前头像 |
| DELETE /api/me/avatar | 登录 | 清除头像 |
| GET /api/profiles/:id/avatar | 匿名 | 当前有效头像；无头像、禁用或退役返回 404 |
| GET /api/courses/:courseId/students/:studentId/academic-record | 当前学期该课程教师 | accountId、schoolNumber、name、department、major、grade |

公开查询旧身份返回 nickname=“已删除”、isDeleted=true、avatarUrl=null；讨论作者也返回 isDeleted，不继续显示旧教师标识。普通公开资料不包含学工号、姓名、院系、专业、年级、密码和内部版本。

academic-record 路径为兼容现有接口保留，读取的是 accounts 的受控字段，不对应独立学籍表。学生不能读取他人资料；教师只可查询自己当前学期所授课程中、当前学期修读的未退役学生。权限不足和目标不存在均返回 404，不授予教师修改基本信息的权限。

头像支持 PNG、JPEG、WebP，最大 2 MiB，Content-Type 必须匹配签名；不接受 SVG、远程 URL 或客户端 R2 键。每次上传独立存储，相同图片也不复用；只保留当前头像，无恢复历史头像功能。服务端在更新引用的同一事务中读取实际被替换的键，然后立即删除旧对象；删除前核对它已无账户引用。角色切换保留正在使用的头像。

上传、更新及即时清理流程登记到 waitUntil；清理最多尝试三次。失败写入尝试清理新对象，清理失败不撤销已成功的头像更新。接受极少量残留对象，不提供 avatar_objects、定时清理任务或清理命令。头像由私有 R2 经 Worker 读取，禁用缓存，设置 nosniff 和受限 CSP。

## 成员密码重置

网站不发送邮件；普通成员忘记密码时联系管理员，由管理员在系统外核实身份后重置，再自行交给用户。唯一管理员使用[外部恢复命令](./组员1-管理员初始化与恢复.md)。

- newPassword 省略或空字符串时随机生成 24 位十六进制密码；手工指定时允许非空短密码，UTF-8 最多 72 字节，不裁剪空白。null 或非字符串返回 400。
- mustChangePassword 可选，默认 false；管理界面的“要求用户重置密码”默认勾选。
- 随机密码只在本次成功响应的 generatedPassword 中返回。列表、详情、日志、审计和前端持久存储不保留明文。
- 登录和 /api/auth/me 返回 mustChangePassword。为 true 时仅允许状态查询、退出和改密，受保护业务返回 403 PASSWORD_CHANGE_REQUIRED，前端进入 /settings/password。
- 用户改密提交 oldPassword、newPassword，新密码至少 8 个 Unicode 字符且 UTF-8 最多 72 字节；强制改密时不能沿用临时密码。当前密码错误返回 400 INVALID_CURRENT_PASSWORD。
- 改密或重置在同一事务更新散列、提升 credential_version、清除改密要求或设置新要求、撤销全部会话及写入审计；重置另外清理该成员的登录和改密限流，保留共享 IP 限流。已获准的其他请求仍按准入规则完成。
- 审计 password.reset 的 fields 为 ["password","mustChangePassword"]，仅记录字段名，不记录字段值。外部运维审计的 actorId 为 null。

## 迁移和协作

新增 `0010_consolidate_accounts.sql` 和对应 Drizzle 快照，旧迁移保持原样。迁移保留 ID、密码散列、凭据版本、现有会话、头像及全部业务记录，合并账户资料并删除 account_roles、student_records、credentials、account_private、avatar_objects；删除邮箱和账户 revision，新增院系、专业、年级、data_generation。历史姓名或学工号的两份记录相互冲突、账号缺少角色时拒绝整笔迁移，不擅自选择覆盖。

授课和修读直接引用 accounts.id；数据库触发器校验新增／修改关系的身份，历史关系允许继续指向已退役账号。账户角色禁止原地修改，必须通过创建新身份的流程切换。

组员 2 同步 nickname、name、单个 role、受控资料字段及新身份 ID，不再发送账户 revision 或头像 If-Match。当前已有页面完成会话、账号列表和密码重置契约调整，新增完整资料／身份管理界面仍按前端计划推进。

组员 3、4 的作者外键继续引用 accounts.id；公开展示使用字段白名单，处理 isDeleted。业务写入携带服务端取得的 dataGeneration 并在 SQL 中校验，不能删除退役账号关联的业务记录，也不能按学工号把旧记录转给新账号。部署新代码前需应用全部迁移；此次实现未执行日常数据库或远程迁移。
