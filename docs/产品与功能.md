# 产品与功能

CourseStack（课栈）面向一所学校，围绕长期存在的课程共享资料、提问和讨论，让内容跨学期积累。学生查找和分享内容，教师组织课程与教学互动，管理员统一维护账号和全站权限。

典型流程是：管理员建立师生账号、课程目录及各学期的课程开设安排；教师直接加入本学期已开设的课程，建立自己的教学班并导入学生。学生上传资料或通过正文链接引用文件版本提问，其他人回答、评论和投票，教师采纳后按学生所属教学班的规则计分。资料更新不改变已有版本链接，学期切换不删除课程内容。

本文描述首版需求；实现范围见[项目入口](../README.md#当前范围)，接口细节见各主题文档。

课程、教学班与权限采用 2026-11-02 确认的目标设计。数据结构、增量迁移及数据库规则已实现并进行隔离验证，业务接口和页面尚待完整适配；设计细节与接续范围见[课程与讨论](./课程与讨论.md#课程学期与教学班目标设计)。

## 账号与访问

- 管理员统一建立学生、教师账号，不开放注册。普通成员以学工号和密码登录，唯一管理员使用独立的密码登录入口。
- 用户维护昵称和头像；姓名、学工号、院系、专业、年级由管理员受控维护，不收集邮箱，不发送邮件。忘记密码时联系管理员核实身份后重置。
- 每个账号只有一个身份。删除账号或切换师生身份保留全部业务数据；切换生成新 ID，旧作者显示“已删除”，新身份不继承旧记录与权限。
- 公开昵称与受控基本信息分开。学生不能查看他人的学籍信息；教师只能查看本人当前学期教学班内学生的必要学籍信息，同课程的其他教师不因此获得该班名单权限。
- 游客可浏览课程、资料信息、问答和评论；发布、互动和下载需要登录。关注或正式修读不是浏览共享内容、提问和回答的前提。
- 作者维护自己的内容；本学期任课教师共同管理整门课程的共享内容与采纳，各自管理本教学班的学生和积分。往届教师不保留整门课程的管理权限，但保留本人内容的作者权限；管理员可跨课程管理。操作权限和内容状态由服务端校验。

## 课程与成员

- 课程由课程号唯一标识，不另设内部课程 ID。课程记录名称和简介，长期保留资料与讨论。
- 管理员创建课程，并决定课程在哪些学期开设。“课程＋学期”的开设安排独立保存，不以有没有教师或学生判断是否开设；课程和开设安排均可以暂时没有教师。
- 同一课程、同一学期可以有多位教师。教师不能创建课程，只能从管理员已确定开设的本学期课程中直接加入，暂不需要审核。
- “教师＋课程＋学期”称为教学班，与学生的行政班不同。教师加入课程学期即建立自己的教学班，同一教师重复加入不能创建重复教学班；教学班可以没有学生。
- 每位教师独立维护本教学班学生。同一学生在同一课程、同一学期至多属于一个教学班，不能同时出现在不同教师的名单中；不同课程或不同学期互不冲突。
- 教师通过名单批量建立本学期教学班的修读关系，这是首版核心功能。名单只能匹配已有学生账号，不能静默创建账号，也不能因导入而自动覆盖其他教师的学生归属。
- 切换当前学期保留课程、历史教学班、修读关系和内容，新学期授课关系不自动继承；教师通过加入管理员已安排的本学期课程取得相应权限。
- 授课、修读与主动关注分开处理；个人入口区分本学期、历年和关注课程。

## 资料与文件版本

- 资料与问题进入同一课程列表，共用标签筛选、排序和分页，不设置分类。资料标题就是公开文件名，简介为 ProseMirror JSON；记录课程、标签、上传者、文件类型、大小和更新时间，展示教师来源标识。
- 资料与问答归属长期课程，不按学期或教学班分割。本学期多位教师共同建设和管理，换教师或换学期不复制、转移或删除已有内容。
- 每个版本只有一个文件，保留历史版本；暂不提供更新说明，用户可在资料评论区说明变化。用户自行准备 ZIP，平台不打包，也不检测重复文件。公开文件名跨版本统一。
- 打开资料即在同一页面展示介绍、版本选择、较大的预览区和评论，默认选中最新可用版本，不可预览时提供下载。支持 PDF、常见图片、Office 和 ZIP，PDF、常见图片提供预览。游客可读资料信息，预览与下载均需登录。
- 上传者维护自己的资料，当前课程教师和管理员按管理范围维护资料与版本。仅整份资料可下架；版本只能删除，删除后不恢复、不复用版本号。上传提供进度、大小与类型限制、失败反馈和安全重试，发布前由后端核验文件。
- 其他内容通过 ProseMirror JSON 中的链接引用资料或具体版本，不另存结构化引用关联。资料本身通过数据库关联版本，发布新版本不改写已有链接，引用不可用时讨论仍可阅读。
- 评论属于整份资料，不按版本分区；收藏同样以整份资料为对象。当前接口见[资料与文件](./资料与文件.md)。

## 问答、评论与投票

- 问题包含课程、标题和正文，可有标签、图片及资料链接；从资料页提问可预填版本链接。提供未解决和近期活跃问题入口，不按结构化文件关联筛选。
- 学生和教师都可回答。教师身份、本课程教师身份和采纳状态分别展示，教师回答不自动置顶。
- 资料、问题和回答都可评论，评论可回复评论；只记录直接父内容，问题评论与正式回答分别展示。
- 编辑器采用 Tiptap，正文存储 ProseMirror JSON，支持常用排版、链接、图片和代码块。标签仅用于问题和资料，可为空。
- 删除内容清空标题、正文和标签并保留关联关系，不可恢复。删除评论时保留占位，其下已有回复照常显示；删除问题、资料或回答时，其下回答和评论一并不再公开。下架保留正文并隐藏整个子分支，可恢复。
- 问题、回答和评论支持赞踩，不允许自投。每人每项至多一票，可撤销或切换，重复操作不累加。采纳答案置顶，其余按净赞数及稳定顺序排序。

## 采纳与课程加分

- 当前课程教师或管理员可采纳、取消或更换答案，每个问题同时至多一个采纳答案；提问者身份不授予采纳权限。
- 有采纳答案时问题为已解决；被采纳答案删除或下架后恢复为未解决；下架恢复后重新显示原采纳，删除则永久移除采纳关系。
- 计分操作应可追溯到课程、学期、教学班、学生、内容、操作者和时间；重试不能重复计分，撤回与调整保留流水，赞踩本身不产生课程加分。
- 每个教学班独立配置提问、回答、采纳、评论、资料首次上传及后续版本的整数分值，默认均为 0；每位教师只能修改自己教学班的规则及手工调整本班学生积分，管理员可跨班管理。
- 自动奖励使用学生在该课程、当前学期所属教学班的规则，与内容操作者或采纳教师属于哪个教学班无关。首次和后续版本分别计分，支持下架撤回和按原值恢复，调整规则不追溯重算已发放积分。
- 积分可按“课程、学期、学生”汇总，教师的查询范围限制到自己的教学班。积分与成绩无关，教师自行说明成绩折算标准。当前仍为课程级配置的实现，见[采纳与加分](./课程与讨论.md#采纳与加分)。

## 搜索、收藏与通知

- 个人空间展示课程动态、本人资料、提问、回答和收藏；收藏支持按课程及内容类型整理。
- 搜索覆盖课程名称、资料标题与简介、文件名、问题和回答文字，可按课程、类型、标签筛选，结果展示摘要并遵循当前可见性。
- 收藏资料的版本或信息更新、收藏讨论的新增或编辑、采纳等重要变化产生通知；本人内容收到回答、评论或采纳也应通知。
- 通知可标记已读并跳转内容。同一事件经多种订阅命中同一用户只通知一次，取消收藏后停止相应后续通知；课程动态、收藏更新和直接通知分别处理。

## 内容管理与可靠性

- 用户可举报资料、问题、回答和评论；课程教师处理本课程举报，管理员处理全站内容，记录审查原因与结果。
- 下架内容不得经普通列表、搜索、预览、下载或历史动态公开。当前实现为发布后审查，最终审核流程待确认。
- 列表与搜索支持分页；加载、空结果、权限不足和失败状态有明确反馈。
- 网络中断、上传失败和重复提交不得造成重复发布、重复计分或虚假成功。文件与元数据保持一致，重要数据应支持备份恢复。

## 待明确与后续范围

待明确：课程号更正与旧链接处理、已有教学班时撤销开设安排的流程、教师退出与交接、学生转班及历史积分归属、名单格式与错误反馈、学期切换时点、历史教学班查询和调分权限、资料适用范围与已发布文件保留期限、编辑器扩展配置、审核方式及性能验收标准。

后续扩展：教务系统对接、文件正文全文检索，以及绑定具体版本的 PDF 页码、幻灯片页码、段落或代码行定位。
