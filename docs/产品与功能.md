# 产品与功能

CourseStack（课栈）面向一所学校，围绕长期存在的课程共享资料、提问和讨论，让内容跨学期积累。学生查找和分享内容，教师组织课程与教学互动，管理员统一维护账号和全站权限。

典型流程是：管理员建立师生账号，教师组织当前学期课程并导入学生，学生上传资料或通过正文链接引用文件版本提问，其他人回答、评论和投票，教师采纳并按规则计分。资料更新不改变已有版本链接，学期切换不删除课程内容。

本文描述首版需求；实现范围见[文档入口](./README.md#当前范围)，接口细节见各主题文档。

## 账号与访问

- 管理员统一建立学生、教师账号，不开放注册。普通成员以学工号和密码登录，唯一管理员使用独立的密码登录入口。
- 用户维护昵称和头像；姓名、学工号、院系、专业、年级由管理员受控维护，不收集邮箱，不发送邮件。忘记密码时联系管理员核实身份后重置。
- 每个账号只有一个身份。删除账号或切换师生身份保留全部业务数据；切换生成新 ID，旧作者显示“已删除”，新身份不继承旧记录与权限。
- 公开昵称与受控基本信息分开。学生不能查看他人的学籍信息；教师查看范围应限于本人当前学期所授课程的当期学生。当前完整资料仅由本人和管理员接口提供，教师资料查询接口尚不提供。
- 游客可浏览课程、资料信息、问答和评论；发布、互动和下载需要登录。关注或正式修读不是浏览共享内容、提问和回答的前提。
- 作者维护自己的内容；当前课程教师管理本课程内容、采纳与加分，管理员可跨课程管理。操作权限和内容状态由服务端校验。

## 课程与成员

- 课程记录名称、唯一编号和简介，提供资料、问答和近期动态入口。
- 每个“课程＋学期”实例恰好有一名教师，可没有学生；只允许新建当前学期实例。教师建课由本人任教，管理员建课须指定教师，不能创建无教师课程。
- 更换教师直接替换原关系，不能先移除唯一教师再添加。切换当前学期保留历史授课、修读关系和课程内容。
- 教师通过名单批量建立本学期修读关系，这是首版核心功能。名单只能匹配已有学生账号，不能静默创建账号。
- 授课、修读与主动关注分开处理；个人入口区分本学期、历年和关注课程。

## 资料与文件版本

- 资料按文件组管理，记录标题、简介、课程、分类、标签、上传者、文件类型、大小、适用范围及更新时间；展示教师来源标识。
- 文件组保留版本、更新说明和历史记录，默认展示最新可用版本。上传者维护自己的资料，课程教师维护本课程资料及分类。
- 首版拟支持 PDF、常见图片、Office 文档和 ZIP；PDF 与常见图片提供预览，其他类型提供信息和下载。上传应有进度、大小与类型限制、失败反馈及重复文件提示。
- 正文通过 ProseMirror JSON 中的链接引用资料或具体版本，数据库不保存内容与引用文件的关联。发布新版本不改写已有链接，引用文件不可用时讨论仍可阅读。
- 资料评论统一位于资料主页，不按文件版本分区。收藏也以文件组为对象。

## 问答、评论与投票

- 问题包含课程、标题和正文，可有标签、图片及资料链接；从资料页提问可预填版本链接。提供未解决和近期活跃问题入口，不按结构化文件关联筛选。
- 学生和教师都可回答。教师身份、本课程教师身份和采纳状态分别展示，教师回答不自动置顶。
- 资料、问题和回答都可评论，评论可回复评论；只记录直接父内容，问题评论与正式回答分别展示。
- 编辑器采用 Tiptap，正文存储 ProseMirror JSON，支持常用排版、链接、图片和代码块；编辑器界面、扩展配置、预览及安全渲染由前端实现。标签仅用于问题和资料，可为空。
- 删除内容将标题、正文和标签设为 NULL，保留时间、请求幂等键及关联关系，不可恢复。删除评论时保留 `deleted` 占位，其下已有回复照常显示；删除问题、资料或回答时，其下回答和评论一并不再公开。`hidden` 下架保留正文并隐藏整个子分支，可恢复。
- 问题、回答和评论支持赞踩，不允许自投。每人每项至多一票，可撤销或切换，重复操作不累加。采纳答案置顶，其余按净赞数及稳定顺序排序。

## 采纳与课程加分

- 当前课程教师或管理员可采纳、取消或更换答案，每个问题同时至多一个采纳答案；提问者身份不授予采纳权限。
- 有采纳答案时问题为已解决；被采纳答案删除或下架后恢复为未解决；下架恢复后重新显示原采纳，删除则永久移除采纳关系。
- 计分操作应可追溯到课程、学期、学生、内容、操作者和时间；重试不能重复计分，撤回与调整保留流水，赞踩本身不产生课程加分。
- 积分按“课程、学期、学生”汇总整数分，分别配置提问、回答、采纳、评论、资料首次上传及后续版本的分值，默认均为 0；首次和后续版本分别计分，支持手工加减分、下架撤回和恢复原值。积分为系统内的课程积分，与成绩无关；教师自行说明成绩折算标准。当前规则与实现边界见[采纳与加分](./课程与讨论.md#采纳与加分)。

## 搜索、收藏与通知

- 个人空间展示课程动态、本人资料、提问、回答和收藏；收藏支持按课程及内容类型整理。
- 搜索覆盖课程名称、资料标题与简介、文件名、问题和回答文字，可按课程、类型、标签筛选，结果展示摘要并遵循当前可见性。
- 收藏资料的版本或信息更新、收藏讨论的新增或编辑、采纳等重要变化产生通知；本人内容收到回答、评论或采纳也应通知。
- 通知可标记已读并跳转内容。同一事件经多种订阅命中同一用户只通知一次，取消收藏后停止相应后续通知；课程动态、收藏更新和直接通知分别处理。

## 内容管理与可靠性

- 用户可举报资料、问题、回答和评论；课程教师处理本课程举报，管理员处理全站内容，记录审查原因与结果。
- 下架内容不得经普通列表、搜索、预览、下载或历史动态公开。当前实现为发布后审查，最终审核流程待确认。
- 列表与搜索支持分页；加载、空结果、权限不足和失败状态有明确反馈。
- 网络中断、上传失败和重复提交不得造成重复发布、重复计分或虚假成功。文件与元数据保持一致，重要数据应支持备份恢复。

## 待明确与后续范围

待明确：教师加入与替换流程、名单格式与错误反馈、学期切换时点、新积分规则细节、文件分类与限制、游客预览范围、编辑器扩展配置、审核方式及性能验收标准。

后续扩展：教务系统对接、文件正文全文检索，以及绑定具体版本的 PDF 页码、幻灯片页码、段落或代码行定位。
