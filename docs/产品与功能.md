# 产品与功能

CourseStack（课栈）面向一所学校，围绕长期存在的课程共享资料、提问和讨论，让内容跨学期积累。学生查找和分享内容，教师组织课程与教学互动，管理员统一维护账号和全站权限。

典型流程是：管理员建立师生账号、课程目录及各学期的课程开设安排；教师直接加入本学期已开设的课程，建立自己的教学班并导入学生。学生上传资料或通过正文链接引用文件版本提问，其他人回答、评论和投票，教师采纳后按学生所属教学班的规则计分。资料更新不改变已有版本链接，学期切换不删除课程内容。

本文描述首版需求；实现范围见[项目入口](../README.md#当前范围)，接口细节见各主题文档。

课程、教学班与权限采用 2026-11-02 确认的目标设计。数据结构、迁移、课程与教学班接口及管理页面已实现并进行隔离验证；名单支持单个学号添加及批量粘贴导入，有效项正常添加，错误项逐项反馈；设计细节与接续范围见[课程与讨论](./课程与讨论.md#课程学期与教学班目标设计)。

## 账号与访问

- 管理员统一建立学生、教师账号，不开放注册。普通成员以学工号和密码登录，唯一管理员使用独立的密码登录入口。
- 管理端支持下载 CSV 模板、上传预检并批量创建师生账号，每次最多500条、2 MiB。有效行可单独创建，已有账号保持不变，同学工号内容冲突逐行提示。可填写初始密码或为每人生成随机密码，默认首次登录改密；结果可下载新建账号凭据和失败记录，网络中断可在原弹窗安全重试。字段和重试规则见[CSV 批量创建账号](./账号与权限.md#csv-批量创建账号)。
- 用户维护昵称和头像；姓名、学工号、院系、专业、年级由管理员受控维护，不收集邮箱，不发送邮件。忘记密码时联系管理员核实身份后重置。
- 每个账号只有一个身份。删除账号或切换师生身份保留全部业务数据；切换生成新 ID，旧作者显示“已删除”，新身份不继承旧记录与权限。
- 公开昵称与受控基本信息分开。学生不能查看他人的学籍信息；教师只能查看本人当前学期教学班内学生的必要学籍信息，同课程的其他教师不因此获得该班名单权限。
- 教师具有公开主页，展示头像、昵称、教师标识，以及授课课程、公开资料、提问、回答、评论五个选项卡和各自数量。授课课程跨学期去重并展示授课学期，内容分页并整项点击进入原文。回答和评论保留必要的公开上下文，不展示受控资料、班级名单或积分；禁用、删除及非教师账号不提供教师主页。
- 游客可浏览课程、资料信息、问答和评论；发布、互动和下载需要登录。收藏或正式修读不是浏览共享内容、提问和回答的前提。
- 作者维护自己的内容；本学期任课教师共同管理整门课程的共享内容与采纳，各自管理本教学班的学生和积分。往届教师不保留整门课程的管理权限，但保留本人内容的作者权限；管理员可跨课程管理。操作权限和内容状态由服务端校验。

## 课程与成员

- 课程由课程号唯一标识，不另设内部课程 ID。课程记录名称和简介，长期保留资料与讨论。
- 管理员创建课程，并决定课程在哪些学期开设。“课程＋学期”的开设安排独立保存，不以有没有教师或学生判断是否开设；课程和开设安排均可以暂时没有教师。
- 同一课程、同一学期可以有多位教师。教师不能创建课程，只能从管理员已确定开设的本学期课程中直接加入，暂不需要审核。
- “教师＋课程＋学期”称为教学班，与学生的行政班不同。教师加入课程学期即建立自己的教学班，同一教师重复加入不能创建重复教学班；教学班可以没有学生。
- 每位教师独立维护本教学班学生。同一学生在同一课程、同一学期至多属于一个教学班，不能同时出现在不同教师的名单中；不同课程或不同学期互不冲突。
- 教师可以从本人当前教学班移除学生。管理员可在任意学期将学生转到同课程同学期的另一个教学班，已有积分和流水随学生转入。单独移除学生会清除该次修读和积分。
- 管理员可以删除任意学期的教学班，同时清除班级规则及仍在班的学生修读记录、积分和相应积分通知。教师交接时先转走需要保留的学生，再删原班。删除该课程在该学期的所有教学班后，可撤销开课安排。
- 教师通过名单批量建立本学期教学班的修读关系，这是首版核心功能。每行一个学号，可从 Excel 复制学号列，单次最多500个非空项；去除首尾空白、忽略空行并去重，保留前导零。名单只能匹配未删除的已有学生账号，同班记录跳过，其他班归属与无效学号逐项反馈；有效项正常添加，不能静默创建账号，也不能因导入而自动覆盖其他教师的学生归属。结果显示新增、已在本班、失败及重复数量，可复制失败学号后修正重试。
- 切换当前学期保留课程、历史教学班、修读关系和内容，新学期授课关系不自动继承；教师通过加入管理员已安排的本学期课程取得相应权限。
- 授课、修读与课程收藏分开处理，主动关注统一为课程收藏；个人入口区分本学期、历年和收藏课程。收藏跨学期保留，不自动建立或取消修读、授课关系。课程公共页提供本人修读（教师为授课）学期下拉框，选择后进入对应学期课程页；资料与问答的独立学期筛选在公共页默认全部，在学期页默认该页学期。

## 资料与文件版本

- 资料与问题进入同一课程列表，共用标签、发布人筛选、排序和分页，不设置分类。资料标题就是公开文件名，简介为 ProseMirror JSON；记录课程、标签、上传者、文件类型、大小和更新时间，展示教师来源标识。
- 资料与问答归属长期课程，按首次发布时的当前学期记录并可筛选，不按学期或教学班隔离访问。本学期多位教师共同建设和管理，换教师或换学期不复制、转移或删除已有内容。
- 每个版本只有一个文件，保留历史版本；暂不提供更新说明，用户可在资料评论区说明变化。用户自行准备 ZIP，平台不打包，也不检测重复文件。公开文件名跨版本统一。
- 打开资料即在同一页面展示介绍、版本选择、较大的预览区和评论，默认选中最新可用版本，不可预览时提供下载。支持 PDF、常见图片、Office 和 ZIP，PDF、常见图片提供预览。游客可读资料信息，预览与下载均需登录。
- 只有所有者可以编辑资料和上传新版本；所有者与管理者都能删除版本，但资料至少保留一个现存版本，最后一个版本只能随整份资料删除。管理者不代替所有者修改正文或文件。仅整份资料可下架，版本删除后不恢复、不复用版本号。上传提供进度、大小与类型限制、失败反馈和安全重试，发布前由后端核验文件。
- 其他内容通过 ProseMirror JSON 中的链接引用资料或具体版本，不另存结构化引用关联。资料本身通过数据库关联版本，发布新版本不改写已有链接，引用不可用时讨论仍可阅读。
- 评论属于整份资料，不按版本分区；收藏同样以整份资料为对象。当前接口见[资料与文件](./资料与文件.md)。

## 问答、评论与投票

- 问题包含课程、标题和正文，可有标签、图片及资料链接。资料或具体版本均通过普通正文链接引用。提供未解决和近期活跃问题入口，不按结构化文件关联筛选。
- 学生和教师都可回答。教师身份、本课程教师身份和采纳状态分别展示，教师回答不自动置顶。
- 所属树为问题→回答、问题→评论、回答→评论、资料→评论、资料→版本。所有评论同级，回复评论另存引用，不形成所属父子关系；问题评论与正式回答分别展示。
- 编辑器采用 Tiptap，正文存储 ProseMirror JSON，支持常用排版、链接、图片和代码块。正文支持 Markdown 图片语法 `![说明](URL)`，外链图片由浏览器直接加载，本地图片每张最多 1 MiB。每次插入本地图片独立存储，编辑删图或删除整篇内容会回收对应文件。标签仅用于问题和资料，可为空。
- 所有者只能删除没有未删除回答或评论、且未被采纳的内容；已下架的讨论也阻止父对象删除。评论之间的回复不影响删除权限。管理者可删除整个所属分支，连带清空子内容正文、标题和标签并删除资料版本，保留必要标识、关联与流水，不可恢复。评论删除或下架不影响回复它的其他评论；删除占位仅在有可见回复时展示。下架保留正文并关闭整个所属分支的公开入口，可恢复。
- 资料、问题、回答和评论均支持赞踩，不允许自投。每人每项至多一票，可撤销或切换，重复操作不累加。资料投票以整份资料为对象，不按文件版本区分。采纳答案置顶，其余按净赞数及稳定顺序排序。

## 采纳与课程加分

- 当前课程教师或管理员可采纳、取消或更换答案，每个问题同时至多一个采纳答案；提问者身份不授予采纳权限。新增或更换采纳需要已设置当前学期。
- 有采纳答案时问题为已解决；被采纳答案删除或下架后恢复为未解决；下架恢复后重新显示原采纳，删除则永久移除采纳关系。
- 计分操作应可追溯到课程、学期、教学班、学生、内容、操作者和时间；重试不能重复计分，撤回与调整保留流水，赞踩本身不产生课程加分。
- 每个教学班独立配置提问、回答、采纳、评论、资料首次上传及后续版本的整数分值，默认均为 0；每位教师只能修改自己教学班的规则及手工调整本班学生积分，管理员可跨班管理。
- 自动奖励使用学生在该课程、当前学期所属教学班的规则，与内容操作者或采纳教师属于哪个教学班无关。首次和后续版本分别计分，删除或下架撤回受影响所属分支的全部自动奖励，上架按每条内容原学期所属教学班的现行规则重新计算，即使学期已结束也只计入原学期；资料后续版本和跨学期采纳的奖励恢复时同样按资料或答案的首次发布学期计算。手工调分保留；仅修改规则不重算已发放积分。
- 积分可按“课程、学期、学生”汇总，教师的查询范围限制到自己的教学班。积分与成绩无关，教师自行说明成绩折算标准。当前实现与接口见[采纳与加分](./课程与讨论.md#采纳与加分)。
- 课程简介提供加分规则与个人加分历史弹窗。学生查看自己当前教学班的规则，并按学期查询本人历史、净积分、原因及时间；本人操作产生的常规积分在右下角提示并提供历史入口；教师手工调分，或他人采纳、内容处理造成的积分变化进入站内通知，不单独弹出提示。

## 搜索、收藏与通知

- 个人空间展示课程动态、本人资料、提问、回答和收藏。课程、整份资料和整个问题讨论统一收藏，仅本人可见，支持按课程及内容类型筛选；重复收藏不改变排序，取消后重新收藏排在前面。下架或删除的收藏保留不可用占位，仍可取消。
- 首页动态来自本学期修读或授课课程与收藏课程的并集，按课程去重；展示新资料、新问题和资料新版本，读取时过滤不可公开内容。收藏资料或问题不会自动收藏其课程；课程收藏不逐条生成站内更新通知。
- [全站搜索](./全站搜索.md)已实现：覆盖课程号、名称与简介、资料标题（公开文件名）、简介与标签、问题标题、正文与标签，以及回答自身正文；支持课程、类型、标签筛选与相关度/更新时间排序。返回摘要和安全高亮，严格遵循公开可见性，不搜索评论和文件内文。
- 收藏更新通知只覆盖问题的新回答、采纳变化和资料的新版本；普通编辑、点赞及关注课程的一般动态不进入通知。本人内容收到回答、评论，评论被回复，以及回答被采纳或取消采纳时通知本人，不弹 toast。
- 通知及已读状态保存在服务端，可标记已读并跳转内容；已读通知保留。通知页默认只看未读，可切换已读或全部，每批最多 20 条，通过“加载更多”继续读取。“全部已读”只处理点击时列表最新通知 ID 及之前的通知，随后到达的通知保持未读。
- 同一事件经多种身份命中同一用户只通知一次，操作的人通过当前页面获得反馈；取消收藏后停止相应后续通知，已有通知保留。直接互动文案优先，不向操作者本人发送该事件通知；接收者在事件发生时确定，重新收藏不补发历史通知。课程动态、收藏更新和直接通知分别处理，接口和迁移规则见[收藏与动态](./收藏与动态.md)。
- 可见标签页每 60 秒独立轮询，恢复可见、聚焦或联网时刷新；不使用 WebSocket，也不跨标签页共享通知缓存。通知页之外只读取未读总数，通知页同时更新最新一批与已加载条目的阅读状态和可见性。通知关联内容不可查看时保留通知和未读数，隐藏标题，不保留标题或正文副本。

## 内容管理与可靠性

- 用户可举报资料、问题、回答和评论；当前课程的所有教师跨教学班共同拥有采纳、举报审查、上下架与完整删除权限，管理员覆盖全站。学生学籍、班级规则和手工调分仍按教学班授权。举报结果为维持现状、下架或删除，内容处理和积分撤回原子提交。举报和管理操作的原因均为选填，管理原因填写后随通知显示，未填写则不显示。
- 下架内容保留正文并关闭公开入口。所有者仍可私下查看、编辑，满足删除条件时也可删除；编辑不会自动上架。管理者在专门的内容审查页查看原文与文件，决定上架或删除。所有者通过外部沟通联系管理者复核，不提供站内申诉、申请上架或连带积分待审流程。管理者下架、上架和删除都通知受影响内容的所有者，包括所属回答和评论的所有者；已被单独下架的内容及其下内容不随上级下架或上架重复通知。删除他人版本也通知资料所有者。
- 列表与搜索支持分页；加载、空结果、权限不足和失败状态有明确反馈。
- 网络中断、上传失败和重复提交不得造成重复发布、重复计分或虚假成功；原样重试复用同一请求，不会重复发布。发布请求已发出而网络中断时，提示内容可能已经发布，修改后再提交前应先确认。文件与元数据保持一致。

## 待明确与后续范围

待明确：课程号更正与旧链接处理、学期切换时点、历史教师的数据访问扩展、资料适用范围与已发布文件保留期限、编辑器扩展配置、审核方式及响应时间验收阈值。首版容量按一所学校、约 100 门长期课程、累计 10 万条内容（含回答和评论，活跃课程约 5,000 条）设计。

后续扩展：教务系统对接、文件正文全文检索，以及绑定具体版本的 PDF 页码、幻灯片页码、段落或代码行定位。
