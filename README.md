# CourseStack

CourseStack（课栈）是面向校内课程的资料共享与问答平台。师生围绕课程整理资料、提出问题和分享解答，让资料与讨论能够跨学期积累，供后续修读同一课程的学生继续使用。

## 当前范围

后端已有账号会话、受控账户资料、课程与讨论、资料上传及版本管理、采纳加分、举报审查和内部供数接口；主站已接入课程、问答、资料页面以及账号与课程管理。已接入管理员建课与开课安排、教师加入教学班、单个学号与批量名单导入及班级独立积分管理，采用[课程与教学班模型](./docs/课程与讨论.md#课程学期与教学班目标设计)。学生可在课程简介查看本班加分规则和个人历史弹窗，本人操作的积分通过 toast 提示，他人操作的积分进入站内通知。已接入所有者私有维护、管理者跨教学班审查、原学期积分重算，以及互动、采纳和管理通知；通知保留服务端已读历史，支持筛选与加载更多。课程、资料和问题已统一收藏，首页动态与收藏更新接入通用通知中心，见[收藏与动态](./docs/收藏与动态.md)。已接入[全站搜索](./docs/全站搜索.md)，覆盖课程、资料、问题与回答。管理员可删除师生账号、切换身份、在同一课程学期内给学生转班或删除教学班。各模块的已实现与待完成部分见对应主题文档。

管理员账号管理已支持 CSV 模板下载、预检与批量创建，包含逐行错误、独立随机初始密码、安全重试及凭据下载，见[CSV 批量创建账号](./docs/账号与权限.md#csv-批量创建账号)。
