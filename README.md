# CourseStack

CourseStack（课栈）是面向校内课程的资料共享与问答平台。师生围绕课程整理资料、提出问题和分享解答，让资料与讨论能够跨学期积累，供后续修读同一课程的学生继续使用。

组内提案材料统一放在 [docs](./docs/)：

- [介绍](./docs/介绍.md)
- [粗略功能列表](./docs/粗略功能列表.md)
- [技术栈和开发](./docs/技术栈和开发.md)
- [分工方案](./docs/分工方案.md)

提案记录项目定位、功能范围和协作分工，具体方案将随开发过程继续完善。

组员3的课程与互动后端见 [backend/README.md](./backend/README.md)，首次启动和提交步骤见 [新手操作](./docs/member3/新手操作.md)。
数据库联调提案见 [database/README.md](./database/README.md)；共享表与加分规则需按 [联调说明](./docs/member3/联调与规则说明.md) 协调。
