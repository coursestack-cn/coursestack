# CourseStack

CourseStack（课栈）是面向校内课程的资料共享与问答平台。师生围绕课程整理资料、提出问题和分享解答，让资料与讨论能够跨学期积累，供后续修读同一课程的学生继续使用。

组内提案材料统一放在 [docs](./docs/)：

- [介绍](./docs/介绍.md)
- [粗略功能列表](./docs/粗略功能列表.md)
- [技术栈和开发](./docs/技术栈和开发.md)
- [分工方案](./docs/分工方案.md)

提案记录项目定位、功能范围和协作分工，具体方案将随开发过程继续完善。

当前已实现组员 1 的账号与资料后端：本地 Workers / D1 / Drizzle 环境，账号与学期关系表，登录会话、账号管理、管理员重置密码、个人资料与头像及受控学籍维护。前端（含管理端）由组员 2 负责，已完成设计基础、通用组件和页面地址规划，业务页面尚未实现。
