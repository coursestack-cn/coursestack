# CourseStack

CourseStack（课栈）是面向校内课程的资料共享与问答平台。师生围绕课程整理资料、提出问题和分享解答，让资料与讨论能够跨学期积累，供后续修读同一课程的学生继续使用。

项目文档从 [docs/README.md](./docs/README.md) 进入，按产品需求、架构开发、账号权限、课程讨论、前端路由及部署运维组织。历史方案与变更通过 Git 查询。

- [产品与功能](./docs/产品与功能.md)：首版范围与业务规则。
- [架构与开发](./docs/架构与开发.md)：技术栈、工程入口与开发环境。
- [后端开发说明](./backend/README.md)：本地启动、检查及数据库初始化。
- [协作分工](./docs/协作分工.md)：模块主责与联调边界。

后端已有账号会话、受控账户资料、课程与讨论、采纳加分、举报审查及内部供数接口；前端已有公共组件、页面框架、路由、登录、账号列表和改密。业务页面与文件、搜索、通知等功能的完成范围见[文档索引](./docs/README.md#当前范围)。
