# CourseStack

CourseStack（课栈）是面向校内课程的资料共享与问答平台。师生围绕课程整理资料、提出问题和分享解答，让资料与讨论能够跨学期积累，供后续修读同一课程的学生继续使用。

## 当前范围

后端已有账号会话、受控账户资料、课程与讨论、资料上传及版本管理、采纳加分、举报审查和内部供数接口；主站已接入课程、问答、资料页面以及账号与课程管理。名单导入、授课与学期管理、首页动态、搜索、收藏和通知仍待实现；课程开设与多教师教学班已确认新的[目标设计](./docs/课程与讨论.md#课程学期与教学班目标设计)，尚待迁移。各模块的已实现与待完成部分见对应主题文档。
